## 一、网页端是什么

句芒智元把客户端变成了一个 7×24 的**远程助手**：在电脑上开启 WebUI 服务后，同一局域网内的手机 / 平板 / 其他电脑用浏览器打开 `/overview`，得到与桌面客户端同一套前端（会话、计划任务、设置、渠道……都可用），外加桌面端没有的**远程审批浮层**。

入口：**设置 → 网关互联 → WebUI**（此卡片仅桌面端显示）；托盘菜单「访问网页端」与全局快捷键可一键打开本机页面。

## 二、开启服务与登录

WebUI 卡内两组内容：

**服务卡**：

- **启用 WebUI** 开关；
- 访问地址（本机 `127.0.0.1:20168` 与局域网 IP）、端口；
- **允许远程访问** 开关：不开则只放行本机访问，开了才允许局域网其他设备连入。

**登录信息卡**：

- 用户名（默认 `admin`）与**初始密码**——首次启用自动生成，**只在首次成功登录前可见，提示「请记录此密码，关闭后将不再显示」**；
- 「修改」用户名 / 密码：改密后其他已登录设备会被登出；忘了密码也没有旧密码校验，直接改一个即可。

> 两个使用习惯要知道：**「允许远程访问」开关重启客户端后回到默认关闭**（想常开就每次启动后开一下，这是当前的安全默认）；**桌面端重启后所有网页端需要重新登录**（会话凭据随进程销毁，属正常行为）。

## 三、扫码配对与手机连接

登录信息卡里的**二维码**（需服务运行 + 已开「允许远程访问」才显示）：

- 内容是局域网地址 + **一次性令牌**（5 分钟有效，扫过即废）；
- 每 4 分钟自动刷新，也可手动「刷新」或「复制链接」发给自己。

**手机连接五步**：

1. 电脑端：开「启用 WebUI」+「允许远程访问」；
2. 手机连**同一 Wi-Fi / 局域网**；
3. 扫二维码（或打开复制来的链接）；
4. 自动完成一次性令牌交换并登录；
5. 浏览器菜单「**添加到主屏幕**」——桌面图标即达，像装了个 App（如实说明：这是网页快捷方式形态，暂无离线能力）。

连接成功后，桌面端设置侧栏底部的手机图标会变绿并显示「已连接 N 台设备」。

## 四、远程审批

智能体要执行命令、改文件时，审批请求会实时推到已连接的网页端：

- 页面右上角浮层卡片（与桌面权限气泡同款视觉）：工具名、来源智能体、命令 / 路径详情；
- 按钮**允许 (Y) / 拒绝 (N) / 始终允许此类操作 (A)**，键盘 `Y` / `N` / `A` 直按；
- 选择类提问（多选题）也能在卡片上直接作答；
- 断线期间做的决定会在重连后补发（超过 30 秒的决定丢弃——过期的审批宁可不作数，不冒险）。

智能体侧会挂起等你的决定，所以人在外面也不会卡死任务。

## 五、网页端能力边界

同一前端按运行形态分流，差异如下：

| 能力 | 网页端 |
|---|---|
| 会话浏览与开始新会话、计划任务、设置（含渠道 / 推送配置） | ✅ 可用 |
| 知识库 / 技能 / 助手的流式输出 | ✅ 可用（实时事件） |
| 远程审批浮层 | ✅ 网页端特色 |
| 本地终端（终端哨兵） | ❌ 仅桌面客户端 |
| 生产日志巡检 | ❌ 仅桌面客户端 |
| 安装更新 | ❌ 提示回桌面端装 |
| WebUI 服务启停 / 初始密码 / 改密 | ❌ 回桌面端 |
| 已存凭据的渠道开关 | ❌ 回桌面端（webui 不回传凭据） |

浏览器访问统一从 `/overview` 进入，其他路径会提示跳转。

## 六、安全模型与使用建议

- 密码以加盐迭代哈希存储，登录失败 **5 次锁定 60 秒**；
- 扫码令牌一次性、5 分钟过期；登录码 60 秒一次性；
- 令牌比对常量时间防时序侧信道；文件接口有扩展名白名单与敏感目录（`.ssh` 等）黑名单；代理接口防 SSRF。

**建议照做**：

- 只在**可信局域网**使用（家用 Wi-Fi、办公网）；服务为明文 HTTP，跨公网裸露有被嗅探风险，公网远程请自担风险或走你自己的安全隧道；
- 初始密码登录后立刻改掉；
- 不用时随手关掉「允许远程访问」。

## 七、常见问题 FAQ

**手机连不上？**
按序查：①「允许远程访问」开了吗（注意重启后会回到关闭）；② 手机和电脑是否同一局域网；③ 端口被占时服务会自动换随机端口——以设置页显示的**实际地址**为准。

**网页端突然整页提示「WebUI 服务已关闭」？**
桌面端把服务关了。回客户端 设置 → 网关互联 重新启用即可，页面会自动恢复。

**登录提示次数过多？**
连续 5 次密码错误锁定约 60 秒，稍等再试；不确定密码就回桌面端改一个。

**二维码提示已失效？**
5 分钟过期属正常，点「刷新」重新生成再扫。

**重启电脑后网页端全部掉登录？**
正常——桌面端重启会销毁会话凭据，重新登录或重新扫码即可。
