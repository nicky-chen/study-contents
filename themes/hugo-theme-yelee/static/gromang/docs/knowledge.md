## 一、知识库是什么

入口：侧栏「扩展」分组 → **「知识库」**。三级形态：

1. **欢迎页**：「新建知识库」「代码图谱」两个大按钮 + 最近知识库卡；
2. **全部列表**：「LLM Wiki」列表，管理多个知识库；
3. **项目内**：左侧三 tab 侧栏（**知识库树 / 文件 / 资料**）+ 工具栏（编辑/预览、搜索、最近活动、关系图谱、深度研究、刷新）+ 标题栏「**问知识库**」按钮。

另有两类系统级特殊项目：**记忆库镜像**（记忆面板的只读 Wiki 视图，问知识库置灰并引导去记忆图谱对话）与**会话记忆库镜像**——它们是[记忆](./memory.md)体系在本页的镜像，不要清空内容（会被拒绝）。

## 二、新建与管理

「新建知识库」：名称 + 资源等级（默认 L2）+ 描述（可选）+ **目录**（必选）。本质是选一个本地文件夹做知识库根，`.gromang-wiki/` 记录项目身份。多库管理：最近列表，卡片菜单有 **Lint 健康检查 / 查看图谱 / 定时摄入 / 清空内容 / 移除**：

- **移除**只是从列表移除，不删磁盘文件；
- **清空内容**删除全部 wiki 页与原始资料（不可恢复，确认弹窗明示）。

## 三、摄入：资料变成知识页

「资料」tab 是知识库的进料口，三类来源：

- **导入文件**（多选）/ **导入文件夹**（递归，自动跳过 .git、node_modules 等与敏感文件）；
- **导入网址**：粘贴多行网址一次最多 50 个（仅 https，禁带凭证，禁止跳转内网，15 秒抓取超时）；
- 支持 77 种格式（文档 / 代码 / 数据等）；单文件上限 100 MB；扫描版 PDF 会明确报「无文本层，请先用 OCR 工具转换」。

**摄入执行器**（手动与定时共用）：选智能体 + 模型 + 权限模式（默认自动），摄入时由它读资料、分析主题与实体、生成页面。

**摄入管线**（自动）：提取文本 → 读取现有知识上下文 → **内容哈希缓存**（内容没变直接跳过，省 token）→ 分析 → **生成页面**（来源摘要页 + 实体页 + 概念页 + 更新日志）→ 整理待审项。**同一时间只跑一个摄入任务**；队列持久化——应用崩溃后重开，横幅提示「上次会话有 N 个资料未完成摄入」，点「继续摄入」接着跑（不自动续跑，防意外烧 token）。

**Review 审阅**：摄入产生的待确认项（矛盾 / 重复 / 缺页 / 待确认 / 建议）进 Review 列表，逐条「标记已处理 / 忽略 / 删除页面 / 转深度研究」。

**Lint 健康检查**：结构检查本地完成（孤页 / 死链 / 无出链），语义检查由智能体跑（矛盾 / 过时 / 缺页 / 建议）；每条问题带修复动作——孤页补链、死链改写目标或建占位页、无出链补链，支持批量修复与转 Review。

**定时摄入**：卡片菜单「定时摄入」→ 选执行器 + 资源等级 + 频率（每 N 分钟 / 小时 / 每天 + 时间点，带预览）→ 自动创建计划任务（任务名 `wiki-ingest-〈项目名〉`），到点增量摄入新资料。管理去[计划任务页](./cron-tasks.md)的「知识库」分类。

## 四、浏览与编辑

- **知识库树**：wiki 页面树（按类型着色）+ **文件树**（项目内全部 md 文件）。
- **Markdown 编辑**：编写 / 预览切换；frontmatter 面板展示类型徽章 / 标题 / 创建时间 / 标签 / 描述 / 来源；`⌘/Ctrl+S` 保存，未保存离开有确认。
- **双链**：正文写 `[[页面名]]`，预览中点击——已存在跳转，不存在**原地建页**。
- **反向链接**：页面底部「反向链接 (N)」。
- **全库搜索**：工具栏放大镜。
- **关系图谱**：Sigma.js 交互画布，按类型或社区着色；过滤器（隐藏索引页 / 孤岛 / 链接数 / 节点大小与间距）；双击节点隐藏；选中节点右侧直接编辑；图谱洞察提示「意外连接 / 知识缺口」。

## 五、问知识库与深度研究

**问知识库**：标题栏按钮打开右侧对话抽屉。检索是**关键词加权匹配**（标题与 frontmatter 优先）取相关页作**引用**——回答带 `[N]` 引用编号，点引用号抽屉内直接预览来源页；可「引用当前文档」聚焦上下文；多轮会话独立保存。

**深度研究**：工具栏显微镜图标（或 Review 条目 / 图谱对话框）发起。流程：输入主题 → **搜索**（智能体用 web 搜索工具收集来源）→ **综合**（流式输出 + 思考过程可折叠）→ **保存**为 `wiki/queries/研究-〈主题〉.md`（结论 + 参考来源列表）。最多 3 个研究并行；web 搜索需要该智能体的 web 工具集已启用。

## 六、代码图谱（项目记忆）

欢迎页「**代码图谱**」入口。副标题即定位：「项目记忆 · 按 repo 同步的代码结构知识」。

- **添加代码库**：本地目录多选，或粘贴仓库地址批量克隆（缓存到 `~/.gromang/wiki/code-repos/`）。远程库**更新前有 dirty 检测**：工作区有未提交修改直接拒绝（「不会自动 reset」），确认更新走 fetch + 硬重置。
- **四个图谱工具**：graphify / GitNexus / codegraph / Understand-Anything。每家独立状态卡：未安装 →「去安装」（跳设置 → 插件 → 图谱插件）→「构建图谱」→ 已构建（重建 / 连接智能体 / 移除标记 / 打开图谱 Web UI）。
- **构建**：在项目专属终端里执行（如 `graphify extract . --code-only && gitnexus analyze`），产物落在仓库目录内（graphify-out/、.gitnexus/ 等）。
- **产出三通道**（构建后显式执行，不自动改写智能体配置）：
  1. **规则文件受管块**：合并各工具能力说明生成「代码知识库」文档，写入该仓库的 AGENTS.md / CLAUDE.md / GEMINI.md（写入前 Git diff 预览）；
  2. **记忆池联动**：同步成功自动把「已用 X 工具建图、产物在哪个目录、改完代码记得重新同步」写进所有已注册记忆池的项目作用域；
  3. 助手运行时注入项目记忆块。
- **新鲜度**：记录构建时的提交与工作区指纹，代码变化后标「图谱需要更新」；同步面板支持**自动同步**（每 15 / 30 / 60 分钟检查 Git 提交）与未提交修改策略。
- **工作区文件**：直接编辑仓库里的 AGENTS.md / CLAUDE.md / GEMINI.md 与各图谱产物目录。
- **图谱 Web UI**：GitNexus / Understand 有面板；graphify 需手动 `graphify export html`。

## 七、挂载：助手与计划任务

- **助手数据目录**选「知识库」：运行时注入知识库工作区说明 + 挂载知识库 MCP（智能体用 `wiki_write_page` 等工具直接写页面）；**计划任务**的定时摄入任务工作目录即项目路径（见[计划任务](./cron-tasks.md)）。
- 知识库与[记忆](./memory.md)是近亲但不同：知识库是资料整理（页面 + 图谱），记忆是会话沉淀的事实——记忆库在知识库页里只是一个镜像视图。

## 八、前置依赖

- **必装插件**：git / node / uv（graphify 的安装依赖）——设置 → 插件；
- **图谱工具**安装命令集中在 设置 → 插件 → 图谱插件；
- **智能体**：摄入 / 语义 Lint / 深度研究需要智能体执行（默认 Hermes）；深度研究的 web 搜索需该智能体的 web 工具集已启用。

## 九、常见问题 FAQ

**摄入卡住不动？**
同一时间只跑一个摄入任务（会提示「正在摄入…请等待完成或取消」）；上次没跑完的队列在重开应用后横幅提示继续。

**PDF 报「无文本层」？**
扫描件。先用 OCR 工具转成文本型 PDF 再导入。

**清空内容和移除的区别？**
移除 = 从列表移掉、磁盘还在；清空内容 = 删光 wiki 页与原始资料，不可恢复。

**「图谱需要更新」一直亮着？**
代码或工作区变了。手动同步或开自动同步（15/30/60 分钟检查 Git 提交）。

**更新远程代码库被拒？**
dirty 检测：有未提交修改会拒绝并保留现场（不自动 reset），先自己处理工作区。

**深度研究报「需要 web 工具集」？**
到该智能体的能力配置里启用 web 搜索工具。

**问知识库的回答里 [N] 是什么？**
引用编号——点它直接预览来源页面；要求回答有据可查。
