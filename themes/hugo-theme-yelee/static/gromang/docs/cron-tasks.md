## 一、计划任务是什么

入口：侧栏「核心」分组 → **「计划任务」**。自建调度内核（30 秒心跳，数据库为唯一事实源），到点驱动智能体在后台无人值守执行——**无需客户端开着**（详见调度守护）。

页头：任务总数徽标、搜索框、「**新建计划**」下拉（**自定义创建** / **从助手预填**——把已启用的助手配置一键带入）。分类 tab 三枚：

| tab | 内容 |
|---|---|
| 自定义 | 你创建的常规任务（含值班巡检任务） |
| 智能化测试 | 页面测试的定时回归任务（见[页面测试](./page-testing.md)） |
| 知识库 | 知识库定时摄入任务 |

与**任务中心**（顶栏铃铛）联动：任务中心聚合全部面板的运行条目，点计划任务条目直达详情；对计划任务点「终止」实际是**暂停后续调度**（已开始的本轮执行继续跑完）。

## 二、创建任务：自定义与助手预填

向导字段一览（「高级设置」折叠区以外）：

| 字段 | 说明 | 默认 |
|---|---|---|
| 任务名称 | 必填 | 助手预填时为「〈助手名〉-定时」 |
| 执行指令 | 发给智能体的指令，必填 | 空 |
| 执行智能体 | 智能体下拉 + 模型选择（可选 Auto） | — |
| 权限模式 | 自动 / 接受编辑 / 跳过权限 / 严格 | 自动 |
| 资源安全等级 | 控制该任务的资源额度档位 | L2 |
| 执行频率 | 五档（见下节） | 每天 09:00 |

「高级设置」折叠区：**消息通知**（单渠道，见第六节）、**重复次数**（留空 = 无限循环；填数字则跑满 N 次后停）、**工作目录**（留空回落用户主目录，可浏览选择）、**验收与重试**（见第四、五节）。

## 三、执行频率：五档

| 档位 | 选项 | 默认 |
|---|---|---|
| 分钟 | 每 5/10/15/30/45 分钟 | 30 分钟 |
| 小时 | 每 1/2/3/4/6/8/12 小时 | 2 小时 |
| **每天**（默认档） | 时间选择器 | 09:00 |
| 每周 | 星期（周一~周日）+ 时间 | 周一 09:00 |
| 自定义 | 间隔 / 每天 / 每周（多选星期）/ 每月（1–31 日）/ **高级（手写表达式）** | 间隔 15 分钟 |

选任何档位都有**实时预览**。高级档手写表达式：五段 cron（`*/5 * * * 1-5`）、`@every Nm`、ISO 时间都认；输入即时校验，非法标红并提示各字段合法范围。每月档选 30/31 日时会提示：没有该日期的月份自动跳过当次。

## 四、验收：怎么算完成

「高级设置 → **怎么算完成**」，四档人话（默认第一档）：

| 档位 | 判定方式 | 花费 |
|---|---|---|
| **跑完就算完成** | 不额外判定，跑完即成功（老任务都是这个行为） | 零 |
| **AI 帮我判断** | 用日常语言写清「怎么算完成」，裁判小模型打分 | 多一次小模型调用，几乎不花钱 |
| **结果里必须有指定内容** | 检查智能体最后一条回复是否包含关键词（逗号/顿号/分号/换行分隔，**全部出现**才算过） | 零，确定性 |
| **运行命令检查** | 在工作目录执行命令，退出码等于期望值才算完成 | 零（给程序员的档位，别写需要交互输入的命令） |

另有 `files` / `manual` 两类手写 JSON 的逃生口（表单不直接暴露，编辑时会提示「另有 N 条非命令验收标准，保存时原样保留」）。

## 五、重试

配了验收才有意义：**最多尝试次数**可选 1–5，默认 1（显示「1 · 1 = 不重试（验收失败即失败）」）。

重试语义：验收不通过时**重跑整个任务**，上一轮的失败摘要会以「[上一轮未通过验收]」注入指令，让智能体知道上一次差在哪。刻意设计成**与调度层的瞬时故障退避互不叠加**——两处都重试会放大花费。

## 六、消息投递

投递渠道（单选；渠道凭据密文存系统钥匙串）：

| 渠道 | 向导内配置 |
|---|---|
| 无（本地） | 不投递，只落库（默认） |
| 钉钉 Token | 群机器人 Webhook 的 access_token（群设置 → 机器人 → 复制 Webhook） |
| 钉钉 CLI | 选群 + 可选机器人（不选机器人 = 以你的用户身份直发） |
| 企微群机器人 | 在 设置 → 消息推送 配置 bot_id / secret |
| 邮件通知 | 选发件账号（主面板邮箱账号）+ 收件人 + 主题 |
| Webhooks | URL（POST JSON；签名密钥在渠道卡片配） |

未启用的渠道在下拉里置灰并标「未启用」，引导到 **设置 → 消息推送** 开通。

投递内容：IM 类发 **markdown**（彩色状态头：成功绿 / 失败红、任务名、深链地址、耗时、验收结论、执行结果摘录）；邮件发纯文本（markdown 自动降级）。结果摘录有长度预算，超长截断并提示完整内容看详情页。**失败也投递**（静默失败最致命）；投递本身失败只记「通知未送达」，不影响任务状态。

## 七、任务卡、详情页与执行历史

**任务卡**（列表页）：启用开关、状态徽章（运行中 / 已暂停 / 错误）、调度人话描述（「每天 09:00」「工作日 09:00」）、智能体与权限模式徽标、通知渠道 chips（无渠道显示「本地」）、下次 / 上次执行时间。删除只能进详情页。

**详情页**头部操作：**暂停 / 恢复**、**立即执行**（触发后 2 秒自动刷新）、**编辑**（复用创建向导）、**删除**（确认弹窗明示不可撤销）。

左栏**执行历史**：触发时间、状态（已完成 / 失败 / 运行中 / 排队中 / 已错过）、失败原因、通知未送达提示、验收结论（已通过 / 需人工确认 / 未通过 · 共 N 次尝试）、耗时；有运行中条目时 5 秒自动轮询。点开**执行详情**弹窗：时间、耗时、逐条验收明细（✓/✕ + 类型标签：命令 / 文件 / 内容 / AI 判断 / 人工）、**完整输出**（markdown 渲染）。

执行详情里还有一个「**沉淀为技能**」按钮：把这次成功的运行轨迹蒸馏成候选技能，进草稿箱人工评审（闭环见[技能沉淀](./skills.md)）。

## 八、调度守护：合上窗口也照跑

计划任务页分类条右侧「**调度守护**」按钮（注册后带状态点）：

- **开机自动运行**开关 + 三色状态：绿 = 运行中，黄 = 已注册未运行，灰 = 未注册；
- 开启后登录系统即常驻调度，任务到期自动执行，无需启动客户端。

平台实现：macOS 注册 LaunchAgent（异常退出自动重启，应用挪位置自动修复注册）；Windows 注册启动项（崩溃后下次登录恢复）；Linux 暂不支持注册（可手动 `gromang --scheduler-daemon`）。

**守护进程与客户端可以同时跑**：任务认领靠数据库唯一约束互斥，同一时刻只会被一个进程执行，绝不重复跑。睡眠唤醒后错过的调度点，在宽限期内（周期一半，2 分钟–2 小时）自动补跑；超宽限记「已错过」留痕并顺延到下一槽。

## 九、hosts 多套配置切换

多套 hosts 方案（如「公司内网 / 家里 / 测试环境」）独立开关切换，开启的方案聚合写入系统 hosts 的受管标记区，标记区以外的原有内容不动。切换需要管理员授权。

入口不在计划任务页：**会话页底部状态栏的 hosts 图标**、**托盘菜单「Hosts 切换…」**（可配全局快捷键）。左栏方案列表（新增 / 重命名 / 删除 / 开关，显示本机 IP），右栏编辑内容（系统 hosts 只读展示；自定义方案可编辑，保存后若已启用自动重新生效）。

## 十、常见问题 FAQ

**任务到点没跑？**
按链排查：任务是否启用 → 详情页「下次执行」时间是否正常 → 客户端开着吗（进程内自带调度兜底）→ 调度守护状态点 → 看 `~/.gromang/logs/scheduler.log` → 执行历史里的失败原因。

**执行失败「任务未配置模型」？**
到任务的编辑向导里给执行智能体指定模型后重试。

**任务突然被停用了？**
调度层连续 5 次瞬时失败（如进程拉不起）会自动停用防止空转；或调度表达式失效（会写明 invalid schedule）。重新启用并修复原因即可。

**验收一直「需人工确认」？**
`manual` / `files` 类型与部分 AI 判断需要人到详情页确认；纯关键词档位则是确定性的，检查关键词是否真的出现在输出里。

**投递的钉钉消息没收到？**
详情页执行历史会显示「通知未送达」及原因：常见是钉钉机器人的自定义关键词不匹配（投递文案含任务名）或渠道凭据失效，去 设置 → 消息推送 检查。

**「终止」能停掉正在跑的这一轮吗？**
不能——「终止」是暂停后续调度，本轮执行会跑完。这是刻意的：不杀死进行中的智能体会话，保留完整输出与轨迹。

## 数据存储

| 数据 | 位置 |
|---|---|
| 任务、执行历史、验收、轨迹 | `~/.gromang/gromang.db`（`cron_jobs` / `cron_runs` / `run_traces`） |
| 每次执行的完整输出 | `~/.gromang/cron/output/<任务ID>/<时间戳>.md` |
| 调度守护日志 / 锁 | `~/.gromang/logs/scheduler.log`、`~/.gromang/cron/daemon.lock` |
| hosts 方案 | `~/.gromang/hosts/` |
| 投递渠道凭据 | 系统钥匙串（密文） |
