## 一、趋势是什么

入口：侧栏「扩展」分组 → **「趋势」**。聚合几十个平台的热榜（微博、知乎、B 站、GitHub Trending、Hacker News……），统一成卡片流：

- 视图 tab 四枚：**当前在榜 / 新增 / 智能分析 / 我的关注**；
- 页头右侧：**设置**下拉（刷新频率 / 平台配置 / 关注订阅）、**筛选**、**刷新数据**；
- 大屏下右侧常驻「跨平台热词」栏（今日热词排行，点击进入热词模式）；
- 点任意卡片 = **应用内打开原文**（按域名复用窗口，不堆浏览器标签）。

## 二、平台清单与配置

设置 → **平台配置**：六个分类共 42 个源可启停——社会热点（微博、今日头条、百度热搜、抖音、B 站、知乎、澎湃、凤凰网、百度贴吧等）、财经（财联社、华尔街见闻、雪球、金十数据等）、科技（IT 之家、少数派、稀土掘金、V2EX、酷安、Solidot、Hacker News、Product Hunt、GitHub Trending、AI HOT 等）、国际（联合早报、参考消息等）、体育、自定义。默认启用 12 家常用源，其余按需开。

平台 tab 可**拖拽排序**（「全部」固定在最左），顺序会被记住。未拖动过时 AI Neuron 社区源保持在「全部」右侧置顶（需公司账号授权，详见设置 → 授权）。

## 三、四种视图

| 视图 | 看什么 |
|---|---|
| **当前在榜** | 最新一轮抓取仍在榜的条目，按当前排名排 |
| **新增** | 本轮**新上榜**的条目——盯新事物的入口 |
| **智能分析** | 跨平台热词聚合工作区（第六节） |
| **我的关注** | 命中你关键词订阅的条目，卡片带分组徽标 |

## 四、筛选与时间翻阅

- **热度阈值**：筛选弹层里开关 + 最低热度值（如 10000），过滤在本地完成。支持「1.2 万」「3.45 亿」这类格式；注意「爆」这类非数字热度的条目，开阈值后会被一并滤掉。
- **时间翻阅**：前一天 / 后一天按钮 + 日期选择，进入「历史模式」看当天全部抓取数据；翻回今天后「后一天」禁用。
- **搜索**：输入任意关键字即切换为**全网搜索**（跨日期匹配全部已抓数据）。
- **一键清除**：全部筛选条件一次清空。

## 五、关键词订阅（我的关注）

设置 → **关注订阅**。规则是结构化的，不是单一关键词：

- **总开关** + **全局排除词**（先过一遍，命中直接丢弃）；
- 多个**分组**，每组：名称、正则开关、每组条数上限、**包含词**（任一命中）、**必含词**（必须全部出现）、**组内排除词**（命中丢弃）；
- 匹配流程：全局排除 → 逐组 → 组内「（包含 OR）AND（必含 AND）AND NOT（排除）」；
- **正则模式**按组开启（大小写不敏感，支持 lookahead），无效正则会报错并跳过该词；
- 配置页有**「预览命中结果（不保存）」**：拿当前数据试跑，零命中时给出排错提示（先查必含词是不是太苛刻、排除词是不是误伤）；
- 命中条目进「我的关注」视图，卡片带分组徽标。

## 六、智能分析：跨平台热词聚合

第四个视图 tab。输入**热点关键词**（必填）+ 日期范围，秒级出聚合报告：

- 概览：命中条数、涉及平台数；
- **平台分布**条形图 + **按天趋势**柱状图；
- 命中条目列表（分页加载，点开直达原文）。

两个前提要知道：**只聚合本地已抓取的数据**（不回溯热榜接口的历史，靠平时定时抓取积累）；**本地只保留 30 天**历史数据——查更早的日期必然为空。

## 七、自动刷新

设置 → **刷新频率**：启用开关（默认开）+ 间隔（5 / 10 / 15 / 30 / 60 / 120 / 240 分钟，默认 30）+ 每次抓取数量上限（全部 / 100 / 200 / 300 / 500，默认 200）。

应用开着就会按间隔自动抓全部启用平台；也可随时手动「刷新数据」，完成后提示「刷新完成 · N/M 平台，共 X 条」——个别平台失败会计入分母，下轮自动重试。

## 八、常见问题 FAQ

**列表是空的？**
默认首次进入需抓取：点右上「刷新数据」。

**开热度阈值后「爆」类条目不见了？**
「爆」是非数字热度值，阈值过滤开启时会被一并滤掉。关掉阈值或调低。

**智能分析查某个历史日期没有数据？**
两个可能：该日期早于本地积累起点，或超过 30 天保留期。保持自动刷新开着积累数据。

**订阅配了却不命中？**
用「预览命中结果」试跑，零命中会有排错提示；最常见是必含词太多、排除词误伤。

**某平台一直失败？**
看刷新完成提示里的成败计数；失败平台自动重试。持续失败可到平台配置里暂时停用该源。
