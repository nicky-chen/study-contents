## 一、页面结构

三栏可拖拽布局：**文件夹侧栏 → 邮件列表 → 阅读区**（点「展开邮件详情」阅读区放大、列表收起）。顶部工具条：返回 / **写邮件** / **工作流**（带待办计数）/ **智能助手** / 搜索框 / **账号**菜单。

没有账号时整页就是添加向导，跟着走即可。

## 二、添加邮箱账号

1. **填邮箱地址**：输入后自动识别服务商（内置常见邮箱预设：QQ / 163 / 126 / Foxmail / Gmail / Outlook / iCloud 等，纯本地识别不发请求）；识别不出就手动填服务器。
2. **服务器设置**（手动时）：IMAP 服务器 + 端口 + 加密（默认 993 / SSL）；SMTP + 端口（默认 465 / TLS）。
3. **密码 / 授权码**：多数服务商需要在网页邮箱里开启 IMAP 并使用**授权码**（应用会按服务商提示你）；微软账号走**浏览器 OAuth 授权**，不填密码。
4. 「测试连接」验证 IMAP 登录，通过后保存。重复添加同一邮箱会被拒绝。

**多账号管理**：「账号」菜单 → 账号详情：同步开关与周期（手动 / 5–60 分钟，默认 10 分钟）、附件下载、桌面通知（可发测试通知）、服务器信息只读展示（密码不回显，改密码需重新添加账号）；侧栏账号可拖拽排序；删除账号会清掉本地缓存邮件。

## 三、文件夹与搜索

- **「全部邮箱」**跨账号聚合统一文件夹（收件箱 / 星标 / 归档 / 已发送 / 草稿 / 废纸篓 / 垃圾邮件等），未读数自动求和；星标是虚拟文件夹排在第二位；组头部一键全局同步。
- 各账号区块显示收件箱未读数（99+ 封顶），可单独同步。
- 文件夹右键：全部标为已读 / 清空废纸篓（破坏性确认）。
- **全文搜索**：主题 / 发件人 / 收件人 / 正文（本地全文索引，多关键词 AND 匹配，50 条结果）；搜索与文件夹浏览互斥，切文件夹自动清空搜索。

## 四、读信与写信

**读信**（会话视图，默认展开最新一封、展开即标已读）：

- 会话级操作：归档 / 恢复到收件箱、举报垃圾邮件、删除（废纸篓内为「彻底删除」不可撤销）、星标、移动到；
- 单封操作：回复 / 全部回复 / 转发（自动生成草稿）、**退订**（邮件带退订头时显示按钮）；
- **正文安全**：默认拦截远程图片（横幅提示，可「本次显示」或对发件人「始终允许」）；正文在沙箱中渲染；可疑链接有安全横幅；
- 附件卡（打开 / 另存为）、图片灯箱（缩放 / 保存）；
- 列表右键还有 **稍后提醒**：今天晚些时候（18:00）/ 明天上午 / 下周一 / 自定义时间。

**写信**（独立窗口式编辑器）：

- 富文本工具齐全：加粗斜体下划线删除线、链接、插入图片（URL 或本地图片）、表格、颜色与高亮、字体字号标题、对齐、列表、引用、撤销重做、清除格式；
- 附件：单文件上限 25 MB；本地图片可直接内嵌正文；
- **草稿**：编辑中每 1.2 秒自动保存本地；「存为草稿」上传服务器草稿箱；「丢弃」删除；
- **发送**：先落库再进异步发送队列，15 秒未确认会提示「已加入发送队列，结果稍后在已发送中确认」；
- **AI 起草**：工具条开关 → 输入指令（如「婉拒周五的会议提议，另约下周二」）AI 直接改写正文；新邮件还能一并生成主题。

## 五、AI 助手：问答 · 邮箱助手 · 自动化

「智能助手」打开右侧抽屉（顶部可选执行智能体与模型，默认自动），三个 Tab：

**本文问答**——先选中一封邮件，针对它提问（多轮对话）。快捷项：提炼关键要点 / 下一步要做什么 / 有什么风险 / **提取行动项**（结构化落库，供工作流使用）/ **优先级评估**（0–100 分 + 理由落库）。

**邮箱助手**——在整个邮箱范围提问，智能体使用**只读**邮箱工具（可搜可读，承诺不发不删不归档）。快捷项：哪些邮件需要回复 / 本周有哪些待办 / 未读里有什么要紧事项 / **生成未读摘要**。

**邮件自动化**——规则**默认只生成建议，确认后才执行**：

- 规则命中 → 进「待确认建议」列表（规则名 / 动作 / 理由），逐条「忽略 / 执行」；
- 「扫描已有邮件」对存量邮件跑一遍规则；
- 新建规则：**用自然语言描述**（如「来自 newsletters@example.com 的邮件归档」），智能体解读成可预览的条件草案（发件人包含 / 文件夹 / 时间范围 / 动作：归档、加星、起草回复），可「预览匹配 N 封」再保存；「自动执行」开关默认关；
- 附带**订阅清理**：列出可退订的发件人（按阅读率排序），确认后批量退订（退订后无法撤销）。

## 六、邮件工作流

「工作流」打开右侧抽屉，四个 Tab：

- **今日收件箱**：只含今天收到的邮件，按「需要处理 / 待确认」分组（依据已提取的行动项与重要度评分），行内显示重要度、行动项、待办数；操作：起草回复 / 转为待办 / 星标——**所有操作均需你确认**；
- **待办**：从邮件转出的待办列表，完成 / 取消；
- **跟进看板**：三状态分组——**已超期**（有待办逾期）/ **等我回复**（最后一封是对方来信）/ **等对方**（最后一封是我方发出）；支持联系人筛选与时间范围；「移出跟进」可撤销。推断基于本地缓存，不改原始邮件；
- **稍后提醒**：所有提醒列表，可调整时间、取消；提醒保留到你主动处理为止。

## 七、安全模型

- 凭据只存**本机**独立邮箱数据库，不出后端、不随任何界面回显（改密需重新添加）；
- IMAP / SMTP **强制 TLS**，端口不支持加密时拒绝降级明文；微软账号走 OAuth 2.0；
- 每个账号绑定独立的资源安全等级（见快速入门的资源等级说明）。

## 八、常见问题 FAQ

**添加账号报「sign-in failed」？**
密码错或该服务商要求授权码——去网页邮箱开启 IMAP、生成授权码再试；微软账号请用「微软登录（浏览器授权）」按钮。

**报端口 / 加密相关错误？**
143 端口走 STARTTLS 的配置常被拒——改用 993 + SSL；自建服务器确认支持 TLS。

**收不到新邮件提醒？**
查账号的同步开关与周期（详情里可发「测试通知」验证链路）；托盘静音会连带静音新邮件音效。

**AI 相关按钮报「请选择已安装且已启用的 Agent」？**
邮箱 AI 需要至少一个可用智能体；顶部选择器里选一个即可。

**删除账号会怎样？**
本地缓存邮件一并清除（服务器邮件不受影响），账号需重新添加。

**正文里的图片看不到？**
远程图片默认拦截（防追踪像素）——横幅里「本次显示」或对该发件人「始终允许」。
