# 句芒智元（Gromang）· 产品功能介绍

> 面向 AI 智能体的一体化桌面控制台——**桌面伴侣看护 · 提供商路由 · 技能与工具编排 · 助手与计划任务 · 知识与记忆 · 用量洞察**。

句芒智元把「你在用哪个 AI 智能体、它正在做什么、它的工具与技能怎么编排、花了多少钱」收进一个常驻桌面伴侣 + 一组轻量窗口。从 Claude Code、Codex、Gemini CLI 到 opencode、Hermes、Cursor……十余种 CLI 智能体，统一看护、统一驱动、统一调度。

- 下载与发版：https://gitee.com/nicky-chin/gromang/releases
- 产品站点：https://nicky-chin.cn/gromang/index.html
- 新用户上手请看姊妹篇：[docs/getting-started.md](./getting-started.md)

## 适合谁用

| 使用者 | 典型诉求 | 主要用到的功能 |
|---|---|---|
| AI 编码代理重度用户（开发者） | 多个 CLI 智能体并行跑任务，想知道"它在干嘛、要不要放行、花了多少" | 会话聚合、桌面伴侣看护、权限气泡、提供商切换与故障转移、用量统计 |
| 自动化 / 效率玩家 | 把智能体变成定时跑、无人值守的生产力 | 助手与套餐、计划任务、智能化测试、终端哨兵 |
| 知识工作者 | 沉淀资料、邮件与长期记忆，越用越懂你 | 知识库、记忆、智能邮箱、趋势热榜 |
| 团队 / 远程协作 | 手机或 IM 里随时指挥家里的智能体 | 网关互联（WebUI 远程）、通信渠道（钉钉 / 微信 / Discord / 邮件）、消息推送 |

## 核心概念速览

| 概念 | 一句话说明 |
|---|---|
| 智能体（Agent） | 外部 CLI 编码代理（Claude Code、Codex 等），接入后可被看护、也可被驱动执行任务 |
| 提供商（Provider） | 各智能体使用的模型 API 供应商；同一份配置可跨智能体复用（统一供应商） |
| 技能（Skill） | 可安装、可同步到各智能体的能力包，中央仓库单一真源（`~/.gromang/skills`） |
| 工具（MCP） | MCP 服务器与桥接工具（HTTP / Dubbo / Datapi / 命令封装成 MCP 工具） |
| 渠道（Channel） | 消息接入通道：钉钉、微信、Discord、邮件、Webhooks、企业微信群机器人等 |
| 会话（Session） | 智能体与用户的对话上下文，跨智能体聚合浏览与搜索 |
| 记忆片段 | 长期记忆条目，可置顶、编辑、遗忘；另有情景语料（对话原文）与记忆图谱 |
| 助手（Assistant） | 预设好身份 / 提示词 / 技能 / 工具的配置层，一键唤起智能体执行任务 |
| 套餐（Recipe） | YAML 定义的场景化任务包：提示词 + 目标智能体 + 技能 + MCP 一键打包运行 |
| 计划任务（Cron） | 自建调度的定时任务，到点驱动智能体执行并把结果投递到渠道 |
| 知识库 | 本地 LLM Wiki：摄入资料生成页面、图谱与可对话知识 |
| 桌面伴侣（桌宠） | 常驻桌面的 Live2D 看护形象，实时演绎智能体状态并承接权限审批 |

## 功能全景

界面分两套侧边栏：**主界面**（日常使用）与**设置中心**（能力配置）。`⌘K / Ctrl+K` 命令面板可直接跳转任意面板。

### 一、主界面 ·「核心」分组

#### 会话

- 聚合 Claude Code / Codex / Gemini CLI / opencode / Hermes 等多家智能体的本地会话记录，统一视图浏览消息全文。
- 按供应商筛选、按项目目录分组；全文搜索会话内容 / 目录 / ID。
- 会话详情：复制"继续命令"、在终端中继续会话、复制项目目录；支持对历史消息分叉开新会话。
- 批量清理本地会话记录（二次确认）；"今天的会话"侧栏直达。
- 附带任务中心：跨面板查看运行中 / 最近结束的任务，可终止运行、暂停后续调度。

#### 助手

- 助手卡片库，按分类筛选（数据洞察 / 报表看板 / 流程自动化 / 领域专家 / 知识问答 / 自定义），支持搜索与排序。
- 运行助手即开对话：选智能体、选模型、调思考强度、添加文件附件、绑定数据目录到知识库；输入 `/` 唤出技能 / 工具 / 快捷短语。
- 编辑器五段式配置：身份、能力（技能 + MCP）、运行规则、快捷短语、投递；内置助手身份锁定只读、可恢复默认。
- 运行历史与版本历史可回溯；助手运行池跨面板存活，切走再切回任务不断。

#### 计划任务

- 自建调度内核（30 秒 tick，SQLite 唯一事实源，双进程同跑安全）。
- 任务卡：启用开关、立即执行、暂停 / 恢复、删除；显示下次 / 上次执行时间与投递目标。
- 创建向导：任务名 + 执行指令 + cron 频率（分钟 / 小时 / 日，带预览）；高级设置可选模型、工作目录、投递渠道（钉钉 / 邮件 / Webhooks 等十余种）。
- 任务详情页查看执行历史与单次执行的输出、耗时、失败原因。
- 调度守护：headless 常驻进程独立跑调度，支持开机自启（macOS LaunchAgent / Windows Run 键）——合上窗口任务照跑。

#### 记忆

- **记忆片段**：按智能体筛选查看长期记忆，置顶 / 编辑 / 忘记 / 恢复 / 删除；支持过滤与排名两种搜索。
- **记忆图谱**：记忆关联的图视图（命名空间着色、节点跳转检索），可"问记忆库"进入记忆对话。
- **情景语料**：对话原文按轮成卡，可搜索、导出、按时间清理。
- **记忆共享**：把句芒智元记忆池开放给其他 agent CLI（ZCode / Claude Code 等）经 MCP 共用；为任意工具生成接入配置。
- 记忆配置：对话后自动提取、收割外部智能体会话、提取模型、召回条数、自动整固阈值；支持从 markdown 重建回灌。

### 二、主界面 ·「扩展」分组

#### 知识库

- 本地 LLM Wiki：新建 / 打开知识库，摄入文件 / 文件夹 / 网址生成 wiki 页面。
- 摄入执行器可选（智能体 · 模型 · 权限模式）；支持定时摄入、Review 审阅、Lint 健康检查三种视图。
- wiki 文件树 + Markdown 编辑 / 预览 + frontmatter 面板；页面关系图谱（按类型 / 社区着色、反向链接、全库搜索）。
- "问知识库"：与知识库对话，深度研究模式输入主题 → 检索 → 综合 → 保存。
- **代码图谱（项目记忆）**：选代码仓库 + 图谱工具（graphify / gitnexus / codegraph / UnderstandAnything）初始化分析，把代码结构知识写入项目记忆；内嵌工作区文件编辑面板。

#### 智能化测试

- 启动受控 Chrome 会话（可见 / 无头模式），实时镜像查看页面并可直接点击、输入回注。
- 登录态管理四种方式：手动登录（专用 profile）、profile 快照、接管已登录浏览器（CDP）、cookie 导入；凭证库保存账号一键代填（密码仅存本机）。
- 无头自动化任务：输入任务描述后台执行，写操作默认拒绝、可按工具预审放行；支持定时执行。
- 命令流审计（工具调用总数 / 成功 / 失败 / 审批），运行归档可看录屏回放、导出流程 JSON、重放、导出离线回看 HTML。
- 站点权限与内置浏览器设置（忽略证书校验、清缓存）；页面内侧边可挂 AI 助手 Dock。

#### 趋势

- 聚合各平台热榜（社会热点 / 财经 / 科技 / 国际 / 体育），平台 tab 可拖拽排序。
- 关键词订阅：分组 + 过滤词（可正则）订阅，命中内容单独成"订阅"视图。
- 当前在榜 / 新增 / 今日全部三种视图；热度阈值过滤、时间前后翻阅。
- 跨平台热词聚合分析：选主题 + 日期范围运行统计；自动刷新间隔可配。

### 三、主界面 · 底部与顶栏入口

#### 智能邮箱（底部快捷入口）

- 多账号 IMAP 收发：统一文件夹侧栏（收件箱 / 星标 / 归档 / 已发送 / 草稿等）+ 全文搜索。
- 读信支持回复 / 转发 / 归档 / 星标 / 移动 / 退订；写信支持附件、存草稿、AI 起草。
- AI 助手：本文问答、全邮箱问答、未读摘要、总结此对话；邮件自动化规则（只生成建议、确认后执行）。
- 邮件工作流：今日收件箱（AI 整理待处理邮件、重要度、转待办、起草回复）、跟进看板（已超期 / 等我回复 / 等对方）、稍后提醒。
- 侧栏邮箱图标带未读红点与账号 / 未读数悬浮提示。

#### 终端哨兵（顶栏「领航台」进入）

- 多标签本地终端：新建 / 重命名标签、选 shell、搜索（正则 / 全词）、字体缩放、导出日志。
- 粘贴保护：多行粘贴弹确认，防止每行立即执行；命令历史点击填入、快速命令可自定义。
- 命令集：钉钉命令集（dws 全量命令按产品分组）与值班命令集一键带入。
- 终端哨兵：检测"终端在等你确认 / 密码"、盯防正则命中、长命令完成 / 失败提醒；提醒弹独立小窗，可直接按 是 / 否 回写。

#### 动感地带（托盘「最近播放」进入）

- 联网搜索歌曲 / 歌单，多音源插件；本地音乐扫描建索引（读 ID3 / FLAC 标签，仅本地不上传）。
- 歌单管理、下载管理（音质选择）、最近播放、我喜欢；底部可拖动展开的播放器。

### 四、桌面伴侣（桌宠）

- **实时状态演绎**：15 种状态——idle / thinking / working / attention（完成）/ error / sweeping / carrying / juggling / roam，外加完整睡眠链（犯困 → 打盹 → 瘫倒 → 熟睡 → 苏醒）。跨会话优先级裁决，绝不错报。
- **权限气泡**：智能体要执行命令、改动文件时弹出 Allow / Deny / 始终允许，热键 Y / N / A 秒级审批；WebUI 模式走浮层审批。
- **会话 HUD**：悬停桌宠即看当前活动会话（状态 + 智能体 + 耗时 + 工作目录），点击聚焦。
- **视线跟踪**：桌宠视线跟随鼠标；内置 5 套 Live2D 模型可换装，支持 PNG 静态模式与 MOD 主题。
- **智能体钩子**：管理接入的智能体，一键安装 / 卸载 hook（写入各智能体配置），实时上报状态与权限请求。
- 托盘与快捷键：迷你模式、勿扰、`Ctrl+Shift+P` 显隐桌宠、`Ctrl+Shift+H` 切换 Hosts、macOS 闪烁告警；音效可自定义。

### 五、设置中心 ·「能力」分组

#### 提供商

- 按智能体分区管理供应商（Claude / Codex / DSH / Gemini / Hermes / OpenCode / Pi），支持启用 / 切换 / 默认 / 复制到其他智能体 / 拖拽排序 / 连通检测。
- **导入当前配置**：把各 CLI 已有配置一键导入为默认供应商，降低首配门槛。
- **统一供应商**：一份配置同时管理多个智能体，保存即自动同步。
- 添加供应商支持"应用专属"与"统一供应商"两种模式；官方 OAuth 登录无需填 API Key。

#### 技能

- 技能库：启用 / 禁用、删除、转本地副本、查重；查看 SKILL.md 文档；同步状态可视化（已同步 / 未同步 / 已分叉）。
- 预设场景：技能组合一键同步到多个智能体；项目工作区按项目查看技能投影与健康度。
- 安装页：技能市场榜单 / Git 仓库 / 本地 zip 三种安装方式；首启自动把散落各应用目录的技能归并到中央仓库。

#### 工具（MCP 四分区）

- **原生 MCP**：添加 / 编辑 MCP 服务器、按智能体开关、JSON 导入、调试、"一键同步"反向导入各 CLI 已有配置。
- **本机 MCP**：终端 / 文件 / 应用 / 截屏等本机操作工具，默认预览模式 + 审批门控 + 审计日志。
- **命令工具**：把本地命令注册成工具供智能体调用。
- **发现**：浏览官方仓库 / 魔搭 MCP 广场 / awesome 目录，搜索一键安装。
- 页头"工具集"弹窗：智能体内置工具集开关（web 搜索、浏览器、视觉、图像生成、TTS、记忆、委派等 20+ 个）。

#### 插件（五个分组）

- **必装插件**：uv / Git / Node.js / npx（含 playwright）安装检测与一键安装。
- **Agent 插件**：各 AI 智能体 CLI 的安装与升级。
- **DSH 插件**：DSH 模型市场。
- **办公插件**：钉钉 CLI（dws）、值班 dutyctl、iPaaS、Office CLI 等业务工具；开源插件市场。
- **图谱插件**：graphify / gitnexus / codegraph / UnderstandAnything 安装与版本检测，服务知识库代码图谱。

### 六、设置中心 ·「偏好」分组

#### 系统

- 外观与语言（简中 / 繁中 / 英文、主题、字体大小）、窗口行为、首选终端。
- **本地路由**：默认 `127.0.0.1:15721`，按智能体接管流量，支持模型映射（haiku / sonnet / opus 等七类）与缓存注入。
- **自动故障转移**：按优先级排队（P1 → P2 → …），失败自动切换；配熔断器（失败率 / 最小请求 / 超时）。
- 整流器、全局出站代理；配置导入导出、数据库自动备份（间隔 / 保留数 / 快照还原）。

#### 桌面伴侣

- 智能体钩子管理（见上）；外观与位置（大小 120–360px、贴靠边缘、PNG 静态模式、MOD 主题、跨显示器）。
- 任务提醒（托盘闪烁间隔 / 时长）；音效（音量 / 静音 / 自定义音频）。

#### 网关互联

- **WebUI 服务**：把客户端当 7×24 远程助手，浏览器 / 手机访问 `http://<局域网IP>:20168`；默认仅本机，放行局域网需开"允许远程访问"。
- **登录**：首启自动生成账号密码；扫码登录（5 分钟 token）；手机 PWA 可远程审批桌面上智能体的权限请求。
- **通信渠道**：接入钉钉（dws 选群 / 机器人 / 触发关键词）、微信（扫码登录 + 配对授权）、Discord（Bot Token）、Webhooks（HMAC 签名）、企业微信群机器人等；凭据测试、待审配对、授权用户管理、渠道对话模型配置。
- **消息推送**：通知投递渠道启停，供计划任务等场景推送结果。

#### 授权

- 钉钉（DWS CLI）授权：系统浏览器 OAuth 登录、账号与到期时间管理。
- 客户端授权登录（IDaaS SSO）：按 scope 授权（如 iPaaS 工作台）。

### 七、设置中心 ·「其他」分组

- Token 活动（每日 / 每周 / 累计：新生成、峰值、缓存命中率、真实消耗）、上下文用量分解、会话总览。
- 明细：请求日志表（供应商 / 计费模型 / 输入输出 / 缓存读写 / 用时 / 首字 / 流式状态）、供应商与模型统计；自定义模型定价算成本，可拉取 models.dev 元数据。

#### 关于

- 版本与更新检查（自动更新走签名校验）、开源链接、首次运行须知、重看功能引导。

## 接入能力总览

### 可看护的 CLI 智能体（19 种）

claude-code、codex、gemini-cli、opencode、hermes、cursor-agent、copilot-cli、qwen-code、kiro、codebuddy、zcode、pi、goose、dsh、qoder、antigravity-cli、codewhale、traecode、workbuddy（以实际版本内置清单为准）。

- **看护链路**（hook 注入）：安装钩子后智能体把状态 / 权限请求上报到本地看护服务，桌宠实时演绎。
- **驱动链路**（协议后端）：助手 / 套餐 / 计划任务可驱动智能体执行任务，流式回传消息 / 思考 / 工具调用；ACP 系走 ACP 桥，Claude / Codex / opencode / zcode / dsh 等有原生协议直连。

### 通信渠道（7 个）

| 渠道 | 接入方式 |
|---|---|
| 钉钉 | dws CLI 以当前登录用户身份收发群消息（触发关键词门控），另支持群机器人通知 |
| 微信 | 扫码登录个人号（配对码授权） |
| Discord | Bot Token（Gateway WebSocket） |
| 邮件 | IMAP 收 + SMTP 发，按发件人自动建用户 |
| Webhooks | 通用 HTTP 双向（HMAC-SHA256 签名） |
| 企业微信群机器人 | 仅出站 webhook 通知 |
| 钉钉通知 | dws 个人号投递，仅通知 |

陌生用户首条消息生成配对码，管理员审批后互通——不会泄露给陌生人。
