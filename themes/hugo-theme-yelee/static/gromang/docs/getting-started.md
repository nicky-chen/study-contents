## 句芒智元是什么

一句话：**一个常驻桌面的"AI 智能体管家"**。

如果你在用 Claude Code、Codex、Gemini CLI、opencode 这类命令行 AI 智能体，句芒智元帮你做四件事：

1. **看护**——桌面伴侣（桌宠）实时演绎每个智能体在干什么：思考中、干活中、出错了、等你审批；智能体要执行危险命令时弹出气泡，你按 Y / N / A 秒级放行或拒绝。
2. **驱动**——内置对话窗口直接指挥任意智能体干活；配置"助手"把常用任务变成一键入口；"计划任务"让它每天定点自动跑，结果推送到钉钉 / 邮箱。
3. **编排**——技能、MCP 工具、提示词、模型提供商，全部在一处管理，一处配置同步到所有智能体。
4. **沉淀**——会话自动归档可搜、用量花费一目了然、长期记忆越用越懂你、资料摄入知识库随问随答。

所有数据存在本机（`~/.gromang`），密钥本地加密，不上云。

## 你是哪种使用者

| 角色 | 你可能的样子 | 建议先用的功能 |
|---|---|---|
| **开发者**（AI 编码重度用户） | 同时开着两三个 CLI 智能体写代码，经常切窗口看进度、手工盯权限弹窗 | 智能体钩子接入 → 桌宠看护 + 权限气泡 → 会话聚合 → 用量统计 |
| **自动化玩家** | 想让 AI 定时跑报表、盯网页、处理重复流程，无人值守 | 助手 → 计划任务（投递到钉钉 / 邮箱）→ 智能化测试 |
| **知识工作者** | 资料散落各处，邮件很多，想让 AI 记住上下文 | 知识库（摄入 + 问知识库）→ 智能邮箱 → 记忆 |
| **远程 / 团队用户** | 人在外面，想用手机或 IM 指挥家里的智能体 | 网关互联（WebUI 扫码 / 手机 PWA 远程审批）→ 通信渠道 |

不确定自己是哪种？按下面"五步上手"走一遍，全都体验到了。

## 安装

1. **下载**：打开 https://gitee.com/nicky-chin/gromang/releases ，下载最新版本：
   - Apple Silicon（M 系列）Mac：`句芒智元-aarch64.dmg`
   - Intel Mac：`句芒智元-x86_64.dmg`
   - Windows / Linux 产物以发布页实际提供的为准。
2. **安装**：macOS 打开 dmg，把「句芒智元」拖入 Applications；首次打开若提示"无法验证开发者"，请在 系统设置 → 隐私与安全性 里点"仍要打开"。
3. **系统要求**：macOS 12.0 及以上。
4. **更新**：应用内置自动更新（带签名校验）。也可在 设置 → 关于 → 检查更新 手动触发；WebUI 模式下更新需回桌面端安装。

## 第一次启动会发生什么

首次打开（全新安装）会经历两段引导，跟着点即可：

**第一段 · 欢迎弹窗「开始之前」**——先确认两处接入情况：

- **智能体接入**：实时检测本机已装的 CLI 智能体；显示"已接入 N 个智能体"或引导你去接入。
- **必装插件**：逐项显示 uv / git / node / python 的安装状态与版本，缺什么装什么。

底部「开始使用」确认后进入第二段。

**第二段 · 功能导览（10 步聚光灯）**——自动带你过一遍：功能导航 → 助手 → 记忆 → 终端哨兵 → 智能化测试 → 提供商 → 技能 → 工具 → 插件 → 会话列表。随时可"跳过引导"；想重看，去 设置 → 系统 → 通用 → 恢复偏好设置。

## 五步上手

以下路径与应用内置引导一致，按顺序做即可跑通第一条链路。

### 第 1 步 · 检查必装插件

设置 → 插件 → 必装插件：确认 **uv、Git、Node.js、npx（含 playwright）** 四项已安装。缺的直接点「安装」一键装；装完 node 后建议重启应用刷新 PATH。

> 这些是知识库图谱分析、智能化测试等功能的运行底座，不装不影响基础对话。

### 第 2 步 · 接入模型提供商

设置 → 提供商：

- **已有 CLI 配置**：点「导入当前配置」，把现有 Claude Code / Codex 等的配置一键导入为默认供应商，零手工。
- **从零添加**：点「添加供应商」，选对应智能体分区；官方渠道走 OAuth 登录则**无需填 API Key**，第三方 / 聚合器只需填 API Key（请求地址已预设）。
- 填完点「检测连通」验证；供应商可拖拽排序、可设默认、可复制到其他智能体分区。

### 第 3 步 · 接入智能体（写入钩子）

设置 → 桌面伴侣 → 智能体钩子：

- 「建议安装」分组里勾选你要看护的智能体，点「一键安装」——应用会把钩子写进该智能体的配置文件（如 `~/.claude/settings.json`），它此后实时上报状态与权限请求。
- **注意：安装 / 更新钩子后，需要新开对话才会被追踪**，已有对话不回溯。
- 卸载同理，一键移除钩子，不留残余。

### 第 4 步 · 开始对话，让桌宠看护你

回到主界面「会话」：

- 点「开始新会话」，选智能体和模型直接聊；或从左侧最近会话列表点开继续。
- 现在去终端里正常使用你的 CLI 智能体——**桌宠会实时演绎它的状态**；它请求执行命令 / 改文件时弹出**权限气泡**，按 `Y`（允许）/ `N`（拒绝）/ `A`（始终允许）。
- 悬停桌宠看活动会话概览（HUD）；`Ctrl+Shift+P`（macOS `⌘⇧P`）全局显隐桌宠；主面板等其他 11 项全局快捷键可在 设置 → 快捷键 查看与自定义。

### 第 5 步 · 进阶玩法（按需）

- **助手**：把常用任务配成卡片（提示词 + 技能 + 工具），一键唤起智能体执行。
- **计划任务**：cron 定时驱动智能体跑任务，结果投递到钉钉 / 邮箱 / Webhooks；开启调度守护后合上窗口也照跑。
- **知识库**：导入文件 / 网址摄入成 wiki，"问知识库"随问随答；代码仓库可生成代码图谱。
- **智能邮箱**：底部邮箱图标添加 IMAP 账号，AI 整理今日待办邮件、起草回复、跟进看板。
- **远程访问**：设置 → 网关互联，扫码或局域网地址用手机打开 WebUI，远程审批智能体权限请求。
- **用量统计**：设置 → 统计，看每个供应商 / 模型的请求与花费。

## 一个典型的工作日

> 场景拼图，帮助理解功能之间怎么串起来——不必一次配齐。

- **早上开机**：桌宠已在任务栏待命；扫一眼"今日会话"，昨夜计划任务的执行报告已躺在钉钉群里。
- **上午写码**：两个终端各跑一个 Claude Code，桌宠一猫一眼盯着；权限气泡"要执行 `rm -rf build`？"——按 `N` 拒掉；长命令跑完了哨兵弹窗提醒。
- **下午处理资料**：把本周报表 PDF 和两个内部网页导入知识库，摄入完"问知识库"直接要结论；顺手让邮箱助手把今日未读整理成待办清单。
- **晚上下班**：新配一个"每天 9 点抓取竞品价格页变化"的智能化测试计划任务，结果推到企业微信群机器人；合上电脑——调度守护会接管定时任务。

## 常见问题 FAQ

**数据存在哪？安全吗？**
全部在本机 `~/.gromang`（SQLite 数据库 + 配置 + 技能仓库 + 日志）；API Key 等密钥走本地加密存储（macOS 可用 Keychain），绝不上云。云同步（WebDAV / S3）是可选项，默认关闭。

**桌宠不显示状态 / 不弹权限气泡？**
确认 设置 → 桌面伴侣 → 智能体钩子 里对应智能体显示"已接入"，并且**安装钩子后新开了对话**；老对话不会回溯。

**忘记 WebUI 密码 / 手机连不上？**
设置 → 网关互联 → WebUI 服务里可查看初始密码、修改密码、重新生成扫码二维码；手机连不上先确认"允许远程访问"已开启且手机与电脑同一局域网（或用配对链接）。

**供应商请求失败怎么办？**
提供商页点「检测连通」排查；配了多个供应商的可开 设置 → 系统 → 自动故障转移，失败自动切下一个。

**支持什么语言？**
界面支持 简体中文 / 繁体中文 / English，设置 → 系统 → 通用 → 语言 切换。

**怎么完全重置 / 卸载？**
应用内 设置 → 系统 → 数据与备份 可导出备份；彻底清除退出应用后删除 `~/.gromang` 目录即可。

**出了问题去哪找日志？**
`~/.gromang/logs/gromang.log`（崩溃日志同目录 `crash.log`），反馈问题时附上。
