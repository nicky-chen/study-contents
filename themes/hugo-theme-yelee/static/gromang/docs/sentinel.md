# 句芒智元 · 智能哨兵

> 三类值守把「需要人回来」的时刻都接管掉：代理会话有人盯，定时业务有人巡，人不在电脑前也有人报。
> 「智能哨兵」是官网对这组值守能力的统称——应用内的落点是**终端哨兵**页：日志巡检、钉钉消息监控（群监控）、智能值班都在这里，终端本身的哨兵盯防也在这里顺手配好。
> 本篇全部功能仅**桌面客户端**可用（网页端不包含终端与生产日志巡检）。刚接触句芒智元请先读[快速入门指南](./getting-started.md)。

## 一、地图：智能哨兵在应用内的落点

从顶栏「**终端哨兵**」图标进入终端页（页名就叫「终端哨兵」：多标签本地终端）。哨兵相关的按钮都在终端页上：

| 入口 | 位置 | 打开什么 |
|---|---|---|
| **日志巡检** | 终端工具栏（列表图标） | 底部展开**合并监控面板**：双 tab「巡检问题 / 钉钉命中消息」，头部还有「过滤规则」「业务设置」「查看全部」 |
| **智能值班** | 终端工具栏（盾牌图标） | 值班报告弹窗 |
| **命令集** | 终端工具栏（书库图标） | 钉钉命令集 + 值班命令集两套目录 |
| **值班设置** | 页头右上（电源图标，巡检启用时带绿点） | 「巡检托管」与「哨兵盯防」两个配置弹窗 |

合并面板点「**查看全部**」进入全页**「日志巡检」**视图，三 tab：**值班报告 / 钉钉消息监控 / 日志巡检**。

监控在跑时进入终端页，面板默认展开；切 tab 只换视图，不会启停监控。

## 二、哨兵盯防：终端六类事件

哨兵盯防管的是**你自己的终端**——在终端页跑长命令、等确认时，不用死盯屏幕。配置入口：页头右上「值班设置 → **哨兵盯防**」：

| 配置项 | 含义 | 范围 / 默认 |
|---|---|---|
| 启用哨兵 | 总开关 | 默认开 |
| 提醒音效 | 事件提示音 | 默认开 |
| 等待判定静止（秒） | 输出静止多久算「在等你」 | 1–60，默认 2 |
| 长命令阈值（秒） | 跑多久算长命令 | 5–3600，默认 60 |
| 确认提示语 | 额外识别「等确认」的提示词，可增删 | 内置项只读 |
| 盯防模式 | 正则，一条一规则，输出命中即提醒 | 如 `listening on.*8080` |

六类事件：**等确认**（`proceed? [Y/n]` 之类）、**要密码**、**长命令完成 / 失败**、**盯防词命中**、**会话暴毙**、**危险命令预确认**。

提醒形态是**独立透明小窗弹卡**（不打断你当前窗口）：完成类 8 秒自动消失、盯防命中 30 秒、等确认/密码/预确认类停留 5 分钟，最多同时 3 张。卡上可直接操作：

- **等确认卡**：点「是 / 否」直接回写终端；
- **预确认卡**：「允许」消卡，「终止」向终端发 Ctrl+C；
- **密码卡**：只能点「已处理」消卡（密码请回终端输，小窗不收密码）。

配套提醒：托盘闪烁（成功绿 / 失败橙）、终端标签徽章、音效（浏览器自动播放限制，首次需点一次小窗解锁声音）。

> 安全细节：回写前会校验「等待槽」是否仍然存在——你切走几分钟后回来，若卡片对应的确认早已过期，不会把 `y` 敲进一个空闲的 shell。

## 三、日志巡检：生产日志自己报警

链路一句话：**采集生产日志 → 分组 → 分诊 → 值班 Agent 深度分析 → 问题报告 →（可选）钉钉投递**。

从零到跑通五步：

1. **授权**：设置 → 授权 → IPAAS 工作台授权（需要有效 SSO 登录态；过期会明确报「未授权 / 已过期」）。
2. **选值班 Agent**：终端页「值班设置 → 巡检托管 → 值班 Agent」，Codex / Claude / Hermes 三选一（日志巡检与智能值班共用这个 Agent；对应 CLI 需已安装）。
3. **启动**：日志巡检页「本机配置」区点「启动」。引擎状态实时显示：检查中 / 运行中 / 配置服务运行中 / 启动条件未满足 / 已停止——条件不满足会列出全部缺项，逐个补齐即可。
4. **业务设置**：登记要巡检的应用与环境——
   - 应用：code / 名称 / 仓库 / 模块 + **应用级钉钉 webhook**（想收钉钉通知必填）；
   - 环境：环境名 / 日志环境 / 日志类型（默认 app）/ 日志级别（默认 ERROR）/ 分支；
   - 巡检限制：查询间隔（分钟，默认 5）；
   - 通知：审查台链接。
5. **看结果**：问题列表按状态筛选——**新发现 / 待确认 / 已确认 / 已修复 / 噪声 / 已忽略**，附环境、应用、时间（24 小时窗，30 条/页）。点开即完整分析报告：

| 报告字段 | 内容 |
|---|---|
| 结论 | 一句话判定 |
| 是否真实问题 | AI 分诊结论 |
| 严重程度 / 影响范围 | 错误次数、受影响接口、时间范围 |
| 证据 | 日志与代码片段 |
| 根因分析 | 假设 + 推理依据 |
| 复现方式 / 处置建议 | 可执行的下一步 |
| 待人工核实 | AI 不确定、需要你确认的点 |
| 相关历史 / 原始 JSON | 关联问题与原始数据 |

**投递**：分析完成且状态为「待确认」时，自动向应用级钉钉 webhook 发 markdown 通知（问题摘要 + 日志摘要 + AI 结论 + 审查台链接）；没配 webhook 则只在本地等你看。**审查台**是随引擎起的本机页面（只绑 127.0.0.1），逐条核对问题用。

## 四、群监控：钉钉消息盯防

按你定的过滤规则盯群消息，命中才打扰你。

1. **授权**：设置 → 授权 → 钉钉（DWS CLI）登录。
2. **过滤规则**（合并面板「过滤规则」按钮）：规则名（必填）；关键词（包含即命中，不区分大小写）；群（下拉选择）；机器人（匹配指定发送者，换群后自动清空重选）；**动作**三选一——**告警 / 归档 / 摘要**；每条规则独立启停。
3. **开启监控**：「钉钉命中消息」tab 右上开关。30 秒一轮拉取；没有启用规则就不拉；配了点名群的只拉点名群（上限 10 个）；消息去重、上限 500 条；重启后回补最近 5 分钟。未命中消息不进列表，只计「已忽略 N 条」。
4. **告警行为**：命中「告警」规则 → 系统通知（标题「钉钉告警：〈规则名〉」，正文含发送人与内容前 80 字）+ 托盘橙色闪烁（10 秒节流）；macOS 上点通知直接跳回应用并打开钉钉 tab。tab 内还可搜索近 3 天命中历史。

## 五、智能值班

智能值班把「值班 Agent」托管起来：巡检定时跑、引擎按班次跑、报告统一看。

**准备两步**：

- 设置 → 插件 → 必装插件 → 安装 **Duty CLI**（「智能值班」，需要 Node.js）；
- 设置 → 授权 → 智能值班（Duty CLI）登录值班中心。

### 巡检托管（定时巡检）

「值班设置 → 巡检托管」：**定时巡检**开关 + 间隔（15 分钟 / 30 分钟 / 1 小时 / 6 小时，默认 30 分钟）+ 「立即巡检」。

- 巡检**不走智能体**：顺序执行只读白名单命令（doctor / status / auth-status / dws status），聚合成报告——快、稳、零 token；
- 报告**保存在本地**，到任务中心 / 计划任务的运行记录里看；
- 巡检查出 FAIL 是「发现」不是「任务失败」，红灯照常进报告。

### 值班引擎托管

- **默认值班模块**：可搜索下拉选择（拉取失败可手填编码）；
- **环境体检**：打开配置即自动跑，FAIL 项给出四类修复引导——缺代码仓 / 模块未启用 / 需先登录 dws / 值班中心登录态缺失，按提示逐项处理；
- 引擎的写操作在终端里执行，见下。

### 快速命令与命令集

- 终端快速命令栏三个现成按钮：**开始值班 / 结束值班 / 跑一轮分析**（未选值班模块时置灰并引导去值班设置）；
- **命令集 → 值班 tab**：按「登录与健康 / 值班班次 / 技术支持 / 中心任务 / 周报」分组，每条带**只读 / 变更**徽标，「带入终端」单行写入。周报那条生成的就是「智能哨兵一周总结」。

### 值班报告

工具栏「智能值班」按钮打开报告列表：工单、Agent、模型、耗时，带「待推送」角标；报告过长自动截断（完整内容在本地文件）；右上「值班中心」直达。**新报告到达时系统通知 + 托盘闪烁**。

### 建议命令（安全设计核心）

钉钉消息监控里勾选若干命中消息 → 点「**问题总结**」→ 分析材料写入本地文件 → 生成交互式智能体命令带入终端。

关键设计：**命令插入不带回车，你按回车才真正执行**；引擎的写操作一律前置确认，结论维持「待人工确认」——引擎不自动关单、不自动处置，处置权始终在你手里。

## 六、通知渠道总览

| 事件 | 提醒方式 |
|---|---|
| 终端等确认 / 密码 / 长命令 / 盯防命中 | 独立小窗卡片（多数可直接回复）+ 托盘闪烁 + 音效 |
| 钉钉告警规则命中 | 系统通知（可点击跳转应用）+ 托盘橙闪 |
| 日志巡检出「待确认」问题 | 应用级钉钉 webhook 投递 |
| 值班报告新到 | 系统通知 + 托盘闪烁 |
| 值班巡检完成 | 本地报告（任务中心查看，不打扰） |

## 八、常见问题 FAQ

**巡检启动报「启动条件未满足」？**
提示里会列出全部缺项（授权 / Agent / Python / git 等），逐项补齐后重试。

**提示「等待巡检响应超时」？**
操作可能仍在后台进行——稍等片刻刷新状态看结果，**不要立即重试**（避免重复启动）。

**钉钉监控显示「拉取失败 N 轮」？**
连续 3 轮失败会自动降级。先查 dws 登录态是否过期（设置 → 授权 → 钉钉），再查网络。

**过滤规则配了却永远不命中？**
检查群与机器人是否配套：机器人的匹配按「发送者」算，换了群以后要在新群里重选机器人，否则是永远命不中的组合。

**哨兵卡片点了没反应？**
回写前会校验等待槽是否仍存在——确认场景可能已变化，回终端看一眼当前状态再操作。

**音效不响？**
浏览器自动播放限制：先点一次提醒小窗解锁，之后就有声了。

**定时巡检的报告去哪看？**
任务中心 / 计划任务的运行记录里，本地保存，不推送。

**网页端（webui）能用智能哨兵吗？**
不能。终端、日志巡检、值班均为桌面客户端专属，远程场景请用手机的 WebUI 远程审批（见快速入门「网关互联」）。
