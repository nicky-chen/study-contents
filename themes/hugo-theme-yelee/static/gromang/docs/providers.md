## 一、地图：模型层的三个入口

| 入口 | 管什么 |

## 二、供应商管理

- **导入当前配置**：把你现有 CLI 的配置一键导入为默认供应商，零手工（「所有数据将安全保存在本地默认供应商中」）。
- **添加供应商**：70+ 预设（官方直连、火山 AgentPlan、智谱 GLM、DeepSeek、MiniMax、SiliconFlow、PackyCode 等）——官方预设**免填 Key**（OAuth 登录），第三方聚合只需填 API Key（请求地址已预设）；也可全手动：名称 / API 地址 / Key / 官网 / 备注 / 模型与倍率。
- **地址管理与测速**：候选地址列表，https 校验、去重、**测速**（返回耗时排序）。
- **检测连通**：卡片按钮——只探测地址可达性（任何 HTTP 响应即「可达」），**不发真实模型请求**；结果三态：连通正常（耗时）/ 连通但较慢 / 无法连通（含 DNS / TLS / 超时提示）。「连通但较慢」与「可达」不代表鉴权与模型配置一定正确。
- 每家供应商可配**单独检测参数**（超时 / 阈值 / 重试）与**成本定价倍率**。
- **排序 / 默认 / 复制**：拖拽排序；「设为默认」；「复制到智能体」把配置跨分区复制（自动做格式转换与端点映射，转换失败提示在目标分区手动新建）；`Ctrl+F` 按名称 / 备注 / 官网搜索。

## 三、自动故障转移

系统设置 →「代理与故障转移」：

1. 「在主页显示故障转移开关」并启用（首次启用建议先配好队列顺序）；
2. **故障转移队列**按 Claude / Codex / Gemini 三个应用分别配置：添加供应商入队、拖拽排 P1 → P2 → …（顺序与主页供应商顺序一致）；
3. **参数九项**（都有默认值与合理范围）：最大重试次数、流式首字超时、流式静默超时、非流式超时、失败阈值、熔断恢复等待、恢复成功阈值、错误率阈值、最小请求数。

行为：请求按队列优先级选供应商，失败自动跳下一个；失败率 / 最小请求数达到阈值触发**熔断**（正常 → 降级 → 熔断三态徽章直接显示在供应商卡片上），熔断的供应商跳过使用，静默期过后放部分流量试探恢复（半开），连续成功才完全恢复。

## 四、本地路由

UI 名就叫「**本地路由**」——本地反代服务，是故障转移、OAuth 反代、模型映射与缓存注入的地基：

- 启用有确认卡；端口默认 15721（1024–65535 可改，改地址 / 端口需先停服务）；
- **按应用接管**：Claude / Codex / Gemini 三个开关——接管后该应用 CLI 的请求改道本地路由（配置里只留占位符 Token，真实 Key 只存本机数据库），关闭时自动恢复原配置（断电级异常也有备份自愈）；OpenCode 不支持接管；
- **模型映射**：按供应商配置里的模型环境变量自动替换请求中的模型名；
- **缓存注入**：自动在请求关键位置注入缓存断点（最多 4 个），TTL 5 分钟 / 1 小时，减少重复 token 计费；
- Claude Desktop 走独立网关配置（有五类状态检查与修复提示）。

## 五、OAuth 直连（Copilot / ChatGPT / Gemini）

OAuth 能力内嵌在供应商表单里（选对应预设即出现）：

- **GitHub Copilot**：设备码授权（可复制 verification URI），支持 github.com 与企业版（GHES），多账号管理与切换；
- **ChatGPT / Codex**：OpenAI 设备码登录 ChatGPT Plus / Pro，把 Claude Code 的请求反代到 Codex 后端；FAST mode 低延迟开关；
- **Gemini**：Google 官方 OAuth，浏览器登录免 Key。

OAuth 类供应商**必须开启本地路由**才能使用（本地反代完成协议转换）；切换时若路由未启动会明确拦截并引导。

## 六、订阅额度

卡片上「配置用量查询」→ 选模板：**官方订阅**（读本机 CLI 的 OAuth 凭据查官方接口，默认关闭）/ Token Plan / 官方余额 / newapi / 灵龙 Token Plan。识别 5 小时 / 7 天 / 30 天 / Pro / Flash 等档位，卡片底部显示进度条与重置倒计时（70% 橙、90% 红阈值）。火山方舟 Coding Plan 需账号级 AccessKey（与推理 Key 是两套凭据，控制台「API 访问密钥」创建）；智谱团队套餐需组织 ID + 项目 ID。

## 七、用量统计

侧栏「其他」→「统计」：

- 时间范围 24 小时 / 7 天 / 30 天 + 日历自定义区间；自动刷新（默认 30 秒）；
- 总览卡：总请求数、总成本、真实消耗 tokens、缓存命中率；滚动窗口条（今日 / 7 天 / 30 天 / 日均）；
- 会话总览：会话数、活跃时长、活跃智能体分布；
- 趋势图 + 月度图 + **上下文构成**（系统前缀 / 会话历史 / 用户输入 / 工具调用 / 子代理 / 推理 / 助手回复各占多少 token）；
- **请求日志表**：时间 / 供应商 / 计费模型 / 输入输出 / 缓存读写 / 成本 / 用时 / 首字延迟 / 状态 / 来源，可开单条详情（倍率 / 流式 / 原始输入）；
- **自定义定价**：按模型录入每百万 tokens 的输入 / 输出 / 缓存成本，可从 models.dev 一键导入；
- 「同步会话日志」把各家 CLI 的会话日志导入统计（覆盖不经路由的请求）。

数据源 = 本地路由日志 + CLI 会话日志同步，全部本地存储。

## 八、密钥安全

- 供应商配置（含 API Key）**只存本机数据库**；渠道 Bot Token、邮箱密码、浏览器代填密码等敏感凭据走本机加密文件（0600）或系统钥匙串；
- 本地路由接管后，各 CLI 配置文件里只有占位符 Token——真实 Key 永不出本机；
- 云同步（WebDAV）是可选功能，默认关闭。

## 九、常见问题 FAQ

**提示「代理接管模式下不可切换到官方供应商」？**
官方账号经代理转发有触发风控的风险，应用直接拦截：先停本地路由，或改用第三方供应商。

**提示「此供应商需要路由服务才能使用」？**
Copilot / ChatGPT OAuth 与格式转换类供应商依赖本地路由，启动路由即可。

**切换供应商后，开着的终端会话还在用旧供应商？**
正常——已开的 CLI 会话沿用启动时的配置，新会话才用新配置；提示条会给「查看会话」列出受影响会话。

**「检测连通」通过就代表能用吗？**
只代表地址可达。官方 OAuth、身份校验中转、签名类 API 三类场景检测必然失败——文案会明示「检测失败不代表供应商不可用」。

**「复制到智能体」失败？**
跨分区复制需要格式转换，少数格式转不过去（提示你到目标分区手动新建）。

**Claude Desktop 分区的状态检查告警？**
五类检查（平台写入支持 / 模型名 / 模型映射 / 网关 Token / 地址一致性），按提示重新切换一次当前供应商即可修复。

**火山用量查询报凭据错误？**
它要的是账号级 AccessKey（与推理 API Key 不同），去火山控制台单独创建。
