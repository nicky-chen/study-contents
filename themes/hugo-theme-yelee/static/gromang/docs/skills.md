## 一、技能是什么

一个技能 = 一个包含 `SKILL.md` 的文件夹。`SKILL.md` 头部用 YAML 写 `name` 与 `description`（没写会回退取正文标题），正文是给智能体的操作说明。

句芒智元把技能做成**中央仓库单一真源**：

- 所有技能统一放在中央仓库，默认 `~/.gromang/skills/`；
- 某家智能体要用哪个技能，就把该技能**投影**（软连接或复制）到它的技能目录；
- 软连接模式下，中央仓库改一处，所有智能体同时生效。

支持分发到的智能体（13 家）：

| 智能体 | 技能目录 |
|---|---|
| Claude Code | `~/.claude/skills` |
| Codex | `~/.codex/skills` |
| Gemini CLI | `~/.gemini/skills` |
| OpenCode | `~/.config/opencode/skills` |
| Hermes | `~/.hermes/skills` |
| Cursor | `~/.cursor/skills` |
| GitHub Copilot | `~/.github/copilot/skills` |
| Claude Desktop | `~/.claude-desktop/skills` |
| DSH | `~/.dsh/skills` |
| CodeBuddy | `~/.codebuddy/skills` |
| Qwen Code | `~/.qwen/skills` |
| ZCode | `~/.zcode/skills` |
| Pi | `~/.pi/agent/skills` |

其中 Claude Code / Codex / Gemini CLI 的目录可以在设置里覆写为自定义路径。

> 应用自带 10 个内置技能（浏览器控制、web 测试、记忆、AI 代码审查委托等），随应用更新维护，不可删除，卡片上不显示删除按钮。

## 二、界面地图

入口：**设置 → 能力 → 技能**。副标题一句话概括了整个功能域：「集中管理技能，按需同步到各个 Agent 与场景」。

进入后默认是**仪表盘**：

- 三张统计卡：**技能库**（技能总数）、**同步覆盖**（投影覆盖情况）、**已连接 Agent**（已安装的智能体数）；
- 主按钮「**打开技能库**」「**安装技能**」；
- 「探索」区四张入口卡：**全局工作区**、**项目工作区**、**预设场景**、**技能沉淀**（草稿箱）；
- 右上角齿轮 →「**存储与同步**」设置弹窗（同步方式、存储位置、自动更新）。

除仪表盘外还有：**技能库**（列表管理）、**安装技能**、**全局工作区**、**预设场景**、**项目工作区**、**技能沉淀**六个子视图，本篇按使用顺序逐一讲。

另外两处快捷入口：会话聊天输入区的「技能」选择器（对话中 `/` 唤起）；助手配置里的「技能」段（助手运行时自动加载）。

## 三、安装技能的四条路

> **先记住一条：安装 ≠ 分发。** 技能装进中央仓库后**不会自动出现在任何智能体里**——要到技能卡上打开对应智能体的同步开关，或应用一个预设场景（见第四、七节）。这不是 bug，是刻意设计：装什么和给谁用，分开决定。

安装页有三个 tab：**浏览榜单**、**本地安装**、**Git 安装**。

### 3.1 技能市场（skills.sh）

「浏览榜单」tab：

1. 榜单三个子 tab：**全部 / 趋势 / 热门**；顶部搜索框输入即搜（结果每批 60 条，「加载更多」再 +60）。
2. 技能卡上点「**一键安装**」：自动下载仓库 zip → 解析 → 装入中央仓库，全程 toast 显示进度（正在克隆仓库 → 正在安装到中央仓库 → 已安装），克隆阶段可取消。
3. 装完去技能库开同步开关（见下节）。

### 3.2 AI Neuron 公司技能库

同在「浏览榜单」tab 的附加来源，面向已授权的公司账号：

- 未登录时列表显示「去授权」；授权在 设置 → 授权 完成（登录失效会提示「登录已失效，请重新授权后再试」）。
- 该来源安装的技能暂不支持自动更新，需要更新时通过 Hub 重新安装。

### 3.3 本地安装（文件夹 / 压缩包）

「本地安装」tab：

- **选择文件夹**：整个目录复制入中央仓库，适合自己开发的技能。
- **选择压缩包**：选 zip 文件，包内必须含 `SKILL.md`（否则提示「ZIP 文件中未找到技能」）。zip 安装仅桌面端支持，网页端（webui）会提示回桌面端操作。
- **扫描结果**：自动扫描各家智能体目录，发现「游离技能」（散落在各家目录、还没进中央仓库的）。可单条「导入」或「**全部导入 (N)**」——这是把散家当归拢进单一真源的路径。部分失败会提示「已导入 N 个技能，M 个失败（列表已刷新）」。

### 3.4 Git 仓库预览安装

「Git 安装」tab，适合从一个 GitHub 仓库挑选多个技能：

1. 输入「仓库 URL」（必须 `https://` 开头），点「**克隆并预览**」。
2. 浅克隆后列出仓库里所有含 `SKILL.md` 的子目录，**每项可勾选、可编辑安装名**。
3. 点「确认安装」逐项入中央仓库，来源记为 Git（后续可走「更新」拉新版本）。

### 安装的通用规则

- 技能名会被清洗：拒绝含 `/` `\` `..`、以 `.` 开头、Windows 保留名、超长名称；
- 同名不同内容不会覆盖，自动装成 `name-2` / `name-3`；内容完全相同则直接复用（幂等）；
- 复制时跳过 `.git`、`.DS_Store`；zip 内的路径穿越会被拦截。

## 四、分发：把技能同步到智能体

### 4.1 单技能分发

技能库里每张技能卡上，**每个已安装智能体各有一个圆点开关**：点亮即同步（投影到该智能体技能目录），熄灭即取消投影。详情面板里能看到「N/M 已同步」的覆盖数。

### 4.2 同步方式：软连接还是复制

仪表盘右上角齿轮 →「存储与同步」→「Skills 同步方式」：

| 方式 | 行为 | 适合 |
|---|---|---|
| **软连接**（默认） | 中央仓库改一处，所有投影即时生效 | 日常首选 |
| **文件复制** | 投影是快照，库更新不自动覆盖副本 | 想在各智能体目录独立改内容时 |

降级链自动兜底：Unix 上软连接创建失败自动降级为复制；Windows 上按 软连接 → junction → 复制 三级降级（Windows 创建软连接需要管理员权限或开发者模式，失败不影响使用，会自动落到 junction / 复制）。

每次同步前会先清理旧投影再写新投影；源目录与目标目录互相嵌套时直接拒绝操作（防误删护栏）。

## 五、更新与卸载

### 5.1 检查更新与自动更新

技能库支持「检查」（单个）、「全部检查」、「更新全部」，卡片上有四种状态角标：**可更新**、**原路径丢失**、**检查失败**、**可能过时**。更新能力按来源区分：

- **Git / skills.sh 来源**：支持「更新」，拉远端新版本；
- **本地 / 导入来源**：走「重新导入」（从原路径重读）；
- **AI Neuron 来源**：暂不支持自动更新，重新安装即可。

「存储与同步」里可配**自动更新**：关闭 / 每 1 / 6 / 24 小时检查一次，可勾选「自动应用更新」（后台自动装新版并通知）。手动检查有 10 分钟缓存，连续点不会重复请求。

### 5.2 卸载

删除技能会级联清理：各智能体投影 → 数据库记录 → 中央仓库目录。**删除不自动备份**（旧版「删除前自动备份」文案已废弃，现版本无此逻辑），确认弹窗想清楚再点。内置技能不可删除。

### 5.3 使用反馈

技能详情面板能看到这个技能「有没有被用起来」：使用轮次（累计 + 近 30 天）、最近使用时间、被哪些智能体用过、被哪些助手引用。统计基于本地纯文本匹配（无 LLM、不上传），保留 180 天。

## 六、全局工作区与冲突处理

「全局工作区」是**复制模式**下的投影管理面板。复制投影会持续比对中央库与各智能体目录里的副本，每对关系显示五种状态之一：

| 状态 | 含义 | 处置 |
|---|---|---|
| 已同步 | 两边一致 | 不用管 |
| 库较新 | 中央仓库有更新 | 从中心恢复（覆盖副本） |
| 本地较新 | 副本被你改过 | 上传到中心（把副本改进收编回中央库） |
| 已分叉 | 两边都改过且不一致 | 二选一：上传到中心 / 从中心恢复 |
| 仅本地 | 中央库里已没有对应技能 | 按需清理或找回 |

注意：复制模式下**你手改的副本不会被静默覆盖**——这就是软连接与复制的本质区别。分叉后到全局工作区里做一次明确决定即可。

## 七、预设场景

预设场景 = 一组技能的打包分发方案。适合「这类活要这几件套」的固定组合。

1. **新建**：名称（必填）+ 描述（可选）+ 图标，卡片支持拖拽排序、重命名、删除（删除不可撤销）。
2. **加技能**：进入场景，把技能「加入预设场景」/「从预设场景移除」。
3. **应用**：卡片上「**应用到默认目标**」——对**全部已安装智能体**按每个技能×每家智能体的开关求出应同步集合，清掉旧预设的过期投影，逐个同步写入；卡片打上「当前」标记。个别失败会提示「已应用，N 项失败」。
4. **细粒度控制**：当前预设下，场景内每个技能仍可按智能体单独开关，改开关立即同步/取消投影，不必重新应用整个预设。也可以只「应用到指定智能体」（不想惊动其他智能体时用）。

## 八、项目工作区：按项目挂载

有些技能只在某个代码仓库里有意义——按项目挂载就是为这场景做的。

**关联项目**（三种方式）：

- 选择目录：直接指定一个项目路径；
- 扫描项目：给定一个根目录，自动识别含 `.git` / `package.json` / `Cargo.toml` / `pyproject.toml` / `SKILL.md` / `.claude` 的子目录；
- 关联工作区：名称 + 路径的虚拟归集。

**挂载与启停**：

- 把中央技能挂载到项目是**复制**（不是软连接）到 `<项目>/<该智能体技能目录>/<技能>`；
- 项目内技能的启停靠目录移动：`skills/` ↔ `skills-disabled/`，停用不删除；
- 双向更新：项目 → 中心（收编项目里的改进）、中心 → 项目（下发新版）。护栏：项目副本较新时，恢复会被拒绝并提示先把本地修改「更新中心」；
- 从工作区**移除项目不删磁盘文件**，只是解除关联。

## 九、技能沉淀：轨迹蒸馏与采纳

这是官网「经验沉淀」特色的技能半边（记忆半边见[记忆沉淀](./memory.md)）：**每次成功干完一件事，都能炼成可复用的技能**。

闭环三步：

1. **蒸馏**：计划任务跑完后，把执行轨迹（计划、工具调用、审批、写文件、终稿）脱敏提炼成**候选技能**，进入仪表盘「探索」区的**技能沉淀**（草稿箱）。蒸馏以轨迹为唯一事实来源，情景语料与记忆只作坑与前提的参考。
2. **评审**：草稿箱人工过目——自动沉淀产出的是**候选**状态（还没人看过），你手动触发的是**草稿**状态。可以采纳、合并到已有技能、或丢弃。**候选永远不会自动上线**。
3. **采纳**：把草稿写入中央仓库并投影到你勾选的智能体（注意叫**采纳**，不叫安装——安装指从市场 / zip / Git 进口）。

草稿在采纳前只存本机，不满意直接丢弃，零成本试错。

## 十、首次启动的自动导入

首次启动时（技能库为空），应用会自动扫描各家智能体目录里含 `SKILL.md` 的子目录，把它们**复制**进中央仓库完成归拢：

- **你原有的文件不会被移动或删除**——是只读复制，原目录原样保留；
- 中央仓库已有同名目录时保留既有内容，不覆盖；
- 导入成功会弹「已自动导入 N 个技能到统一管理」；
- 失败不用慌：打开技能页用「本地安装 → 扫描结果」手动导入，或重启再试（失败后下次启动还会重试）。

之后每次启动还有一个静默的「孤儿导入」：中央仓库磁盘上出现、但数据库没记录的技能目录会被自动补登记。

存储位置可以在「存储与同步」里切换（`~/.gromang/skills` ↔ `~/.agents/skills`，后者是 Agent Skills 开放标准目录）。切换时会整库搬迁，有技能时弹确认「将移动 N 个技能到新位置，是否继续？」。

## 十一、数据存储

| 数据 | 位置 |
|---|---|
| 技能中央仓库 | `~/.gromang/skills/`（默认，可切 `~/.agents/skills/`） |
| 元数据镜像（可 git 同步、可用于重建数据库） | `<中央仓库>/.skill-manager/` |
| 技能元数据、投影、预设、项目、使用统计 | `~/.gromang/gromang.db` |
| 技能正文 | 就在各技能目录的 `SKILL.md`，改文件即时生效（软连接模式下所有智能体同步可见） |

## 十二、常见问题 FAQ

**装完了，agent 里怎么看不到？**
安装 ≠ 分发。去技能库点亮对应智能体的圆点开关，或应用预设场景。

**软连接和复制该选哪个？**
默认软连接即可（一处改、处处生效）。只有当你在某智能体目录里独立维护内容、不想被中央库覆盖时才选复制；复制的手改不会静默丢失，分叉后在全局工作区二选一。

**Windows 上软连接报错 / 被静默换成了复制？**
Windows 创建软连接需要管理员权限或开发者模式。不满足时自动降级：软连接 → junction → 复制，功能不受影响。

**更新按钮对某些技能不可用？**
按来源走不同通道：Git / skills.sh 用「更新」；本地 / 导入用「重新导入」；AI Neuron 来源暂不支持自动更新。没有来源记录的技能无法更新。

**删除技能有备份吗？**
没有。删除是级联清理（投影 → 数据库 → 中央库目录），确认前想清楚。内置技能不可删除。

**技能名后面出现 `-2`？**
同名但内容不同的技能不会覆盖旧版，会自动命名 `name-2`。想替换就先删旧的再装。

**装技能一直转圈 / 超时？**
下载仓库超时上限 120 秒，先查网络；GitHub 返回 403 是请求频率过高，429 稍后再试，404 检查仓库地址。搜索 15 秒超时同样重试即可。

**zip 装不了？**
两个常见原因：包里没有 `SKILL.md`（技能必须含此文件）；或你在网页端操作（zip 安装仅桌面端支持）。

**手改了某智能体目录里的技能副本，更新丢了？**
复制模式下副本手改不会被覆盖——去全局工作区看状态：本地较新 / 已分叉时用「上传到中心」把改进收编回中央库。

**想给不同项目不同的技能组合？**
技能层面用项目工作区按项目挂载；智能体整组合切换用预设场景（应用即整体投影）。
