## 一、状态演绎

桌宠用 15 种状态实时演绎智能体群此刻的整体状态：

- **工作类**：思考中 / 干活中 / 多任务（并行子任务）/ 清理中（上下文整理）；
- **结果类**：已完成（attention）/ 出错；
- **提醒类**：有待办事项（权限请求、提问等）；
- **闲适类**：待机 / 闲逛；
- **睡眠链**：待机一段时间后依次 犯困 → 打盹 → 瘫倒 → 熟睡；任何智能体有新动作立即醒来恢复真实状态；点击熟睡的它可直接唤醒。

裁决规则：同时有多个会话时显示**优先级最高**的状态（出错 > 提醒 > 清理 > 完成 > 搬运 / 多任务 > 干活 > 思考 > 待机 > 睡觉），绝不会用一个会话的「待机」盖住另一个会话的「干活」；有待审批的权限请求时强制显示提醒态。完成 / 出错这类瞬态展示约 4 秒后回落；后台还有任务没跑完时，「完成」会刻意延迟庆祝。

## 二、权限气泡：秒级审批

智能体要执行命令、改文件时，屏幕右缘弹出**权限气泡**（不抢焦点）：

- 卡片内容：工具名彩色标签 + 来源智能体 + 等宽字体命令 / 路径详情；
- 按钮：**允许 (Y) / 拒绝 (N) / 始终允许此类操作 (A) / 本会话始终允许 (S)**，后两个更激进选项收进「···」菜单；键盘 `Y / N / A` 直按；
- 「始终允许」会把规则写入该智能体自己的配置（按钮悬停可预览规则内容）；「本会话始终允许」只在当前会话生效、不落盘；
- 智能体中途提问（选择类问题）也会弹成问答卡，直接作答；
- 一次弹一张，答完立刻弹下一条——队列不清空不消失。

嫌打扰可以在设置里一键隐藏气泡，或直接开「全自动放行」（重启后复位，建议只在跑可信任务时用）。

## 三、会话 HUD：悬停看全局

鼠标悬停桌宠（约 1.5–5 秒，按形象而定）弹出 **HUD 面板**：当前所有活跃会话的列表——状态点 + 智能体 + 来源（测试 / 渠道 / 知识库 / 邮箱…）+ 状态 + 耗时。默认 4 行，可展开到 12 行。

- 任务完成或有待审批时 HUD 自动弹出；
- 无活动 5 分钟自动隐藏（30 分钟硬上限）；手动关掉后 10 秒内不再自动弹；
- **点击任意一行**：聚焦该会话的终端窗口（测试类会话跳对应页面）。

## 四、交互细节

- **拖动**：随意挪位置（位置会记住），拖到屏幕边缘自动吸附；拖去另一台显示器也能跟过去。
- **缩放**：悬停显示侧边工具条，120–360px 无级缩放；「跨显示器保持大小」可开关。
- **视线跟随**：它的目光跟着你的鼠标走。
- **点击**：完成 / 出错态点击收起回待机；睡觉时点击唤醒；待机时点击会眨眼；**1.2 秒内连点三下**它会烦躁地抖一抖（抗议你摸它）。
- **悬停**：轻微放大；MOD 形象还有随机状态小气泡与问候语。

## 五、右键菜单

右键桌宠：**MOD 换装**、**休眠（免打扰）**、**全自动放行**、**终端哨兵**、**音乐播放**（`⌘/Ctrl+Shift+M`）、**记忆共享**、**最近会话**（今天 ≤8 条 + 近 7 天二级菜单）、**设置**、**模型用量**（已开额度查询的供应商按档位显示百分比）、**隐藏 / 显示伴侣**、**退出**。

其中「**休眠（免打扰）**」是轻量模式：关闭主窗口只留托盘 + 桌宠，机器最省；再点「退出」才是真退出。

## 六、设置全集

设置 → 桌面伴侣：

| 分组 | 项目 |
|---|---|
| 外观与位置 | 启动开关、大小（120–360px）、贴靠屏幕边缘、关闭 MOD 换装（改用 PNG 静态图）、启用一言（一言 / 古诗词）、Live2D 形象库（下载 / 更新 / 删除，下载含大小与版权确认）、跨显示器保持大小 |
| 任务提醒 | 任务完成时闪烁托盘、托盘未读数、隐藏气泡、权限气泡开关、通知气泡 6 秒自动收起、闪烁间隔（200–2000ms）与时长（0 = 持续到点击） |
| 音效 | 静音、音量、自定义音效文件（完成 / 确认两个槽位，支持 mp3 / wav / ogg 等，可试听） |

托盘闪烁语义：完成 = 绿色闪、有待办 = 橙色闪；点击闪烁的托盘图标直接跳到待审批卡片或对应会话。

## 七、智能体钩子

桌宠的一切都依赖智能体把状态上报进来——**设置 → 桌面伴侣 → 智能体钩子**里逐家安装 / 卸载 / 修复，也支持批量安装、批量清理、「自动管理 Claude 钩子」开关。各家上报方式不同（钩子 / 扩展 / 插件事件 / 日志轮询），面板会标注；个别智能体有特别提示（Codex 钩子健康告警、ZCode 需新开对话才被追踪、Trae 需在其设置里手动启用 Hooks）。

## 八、常见问题 FAQ

**桌宠不显示？**
按序查：设置里「启动桌面伴侣」开了吗 → 智能体钩子装了吗 → 未授权（登录过期）时它会刻意隐藏，重新授权后恢复 → Live2D 渲染连续失败会自动回退静态图。

**状态不动 / 和实际对不上？**
钩子没装或没生效（装完钩子要**新开对话**）；窗口重载后会主动重新同步一帧状态。

**桌宠卡住拖不动？**
极少数情况下渲染进程卡死，应用有自愈看门狗（自动重载 / 重建窗口，最多重试 3 次）；等几秒或重启应用即可。

**权限气泡一次弹太多？**
单槽队列逐条处理；不想逐条看就用「本会话始终允许」或「全自动放行」（谨慎）。

**想让它彻底安静？**
隐藏气泡 + 关音效 + 关任务完成闪烁，或直接右键「隐藏伴侣」。
