## 一、界面结构

动感地带内五个 tab：**本地音乐 / 歌单 / 最近播放 / 下载管理 / 插件**，顶部是联网搜索框（搜索时内容区整体切到搜索结果，按音源插件分栏）。

**播放器是全局的**：收起时是屏幕右边缘的浮动圆球（任何页面都在），播放时黑胶旋转；单击展开右侧面板，右键浮球出迷你菜单。

## 二、联网搜索与音源插件

搜索支持四类目标：**歌曲 / 专辑 / 作者 / 歌单**。

关键机制：**联网音源全部来自你安装的插件**（不装插件就没有联网结果）。搜索结果按插件分栏，只搜当前选中的插件，结果与报错都按插件缓存——某个源挂了不影响其他源，在它的分栏里点重试即可。

- 曲目右键：**下一首播放 / 加入歌单 / 下载**；
- 专辑、歌单卡片点开详情：封面、播放全部、整批量「添加到歌单」、曲目搜索。

## 三、插件：安装、管理与 AI 生成

**安装**（「插件」tab → 安装对话框，两种模式）：

- **远程 URL**：粘贴插件 `.js` 地址，或订阅 JSON 链接（一次装一批，自动展开，有深度与数量上限防恶意递归）；
- **粘贴代码**：直接贴插件源码。

防呆提示齐全：重复安装（哈希相同）、降版本安装、订阅循环引用都会明确报错。插件运行在沙箱里，网络请求经本地代理转发。

**管理**：启用 / 停用、卸载（不可恢复）、更新（单个 / 全部）、配置变量（改完需重启插件或应用生效）、订阅管理、导入单曲 / 导入歌单。

**AI 生成插件**：这是动感地带的隐藏大招——在会话输入框键入 `/musicfree-plugin-dev` 调出内置技能，让智能体从零给你写一个音源插件（比如你常用的音乐站），写完直接安装。

## 四、本地音乐

「本地音乐」tab →「扫描文件夹」：

1. 添加一个或多个目录；
2. 勾选「过滤时长小于 1 分钟的音频」（默认勾选，滤掉各种提示音）；
3. 「开始扫描」，逐目录建索引——**只建本地索引，不上传任何文件**。

支持 11 种格式（mp3 / flac / m4a / aac / ogg / opus / wav / ape / wv / mka），自动读标签（标题 / 艺术家 / 专辑 / 时长 / 内嵌歌词），读不出来回退文件名。

本地曲库四个子视图：单曲 / 歌手 / 专辑 / 文件夹；文件夹可单独重扫或移除。曲目右键：下一首播放 / 加入歌单 / 在文件夹中显示 / **删除本地文件**（真删磁盘文件，确认弹窗不是吓唬人）。

## 五、歌单

- 「新建歌单」（名称上限 50 字）；搜索结果、本地、最近播放各处右键「加入歌单」；
- 歌单卡片右键：重命名 / 删除；详情页：播放全部、歌单内搜索、曲目右键移除；
- 曲目顺序按加入顺序排列（暂不支持拖拽排序）。

## 六、下载管理

- **音质四档**：低 / 标准 / 高品质 / 无损。播放器面板里选音质，下载用当前音质；期望音质解析失败时自动向更高、更低档回退，全部失败提示「无法解析下载地址」。
- **下载位置**：默认 `~/.gromang/music-downloads/`，可更改目录、恢复默认、一键打开文件夹。
- 队列 / 已完成两栏，实时进度；行操作：取消 / 重试 / 删除 / 播放。
- **删除分两级**：仅删下载记录，或连本地文件一起删（不可撤销，均需确认）。

## 七、最近播放

切歌自动记录（上限 100 条，跨重启保留）。支持播放全部、搜索、行内下载 / 移除；「清空记录」用 3 秒内双击确认防误触。

## 八、播放器详解

**收起态**（右边缘浮动圆球）：

- 可沿右边缘**上下拖动**挪位置；单击展开面板；
- 播放中黑胶旋转 + 状态脉冲；右键浮球出迷你菜单（播放 / 上一首 / 下一首 / 循环模式）。

**展开态**（右侧面板，宽度可拖动并记住）：

- 正在播放：标题 + 音源徽标 + 大封面 + **音质下拉** + 下载 + 加入歌单；
- 可拖进度条；循环四档：**顺序 / 列表循环（默认）/ 单曲 / 随机**（随机进出会保存 / 恢复原顺序）；
- 音量垂直滑杆 + **0.25–2 倍连续变速**；
- 播放队列：双击任意条目立即播放、移除单项、清空需确认。

**键盘**：`Space` 播放 / 暂停，`←` `→` 快退快进 5 秒，`↑` `↓` 音量 ±5%。锁屏 / 耳机线控（系统媒体控制）也接管播放操作。

音量、倍速、音质、循环模式都会记住；**播放队列不持久化**——重启应用后队列清空，去「最近播放」一键找回。

## 九、常见问题 FAQ

**搜索没有任何结果？**
联网音源靠插件：先去「插件」tab 装，或用 `/musicfree-plugin-dev` 让 AI 写一个。

**某个插件源的歌播放报错、也没提示？**
该插件被停用或卸载后，旧曲目解析不到地址，播放器进入错误状态（静默）。重新启用 / 更新插件，或换其他源。

**下载提示「无法解析下载地址」？**
音源失效或该音质无资源：换一档音质重试，或更新插件。

**重启后播放队列空了？**
设计如此（队列不持久化）；最近播放里有完整记录。

**插件装了但搜不到歌？**
看插件分栏内的报错信息（网络 / 源站改版）；更新插件或反馈给插件作者。

**删除本地文件真的删磁盘文件吗？**
是。确认弹窗里写明不可撤销，慎点。
