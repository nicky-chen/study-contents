## 一、助手是什么

入口：侧栏「核心」分组 → **「助手」**。一句话定位：**助手的配置层**——把「用哪个智能体、什么提示词、哪些技能和工具、什么权限」预先打包，之后每次运行只需一句话。

应用内置 3 个开箱即用的内置助手（工作报告 / 代码审查 / 钉钉办公），也支持从模板新建、复制改造、导入导出 DSL 交换配置。

## 二、卡片库

卡片按五类分组：**数据洞察 / 报表看板 / 流程自动化 / 领域专家 / 自定义**（外加「全部」）。卡片上直接看得到：头像、名称与资源等级徽章、「内置」徽章、描述、智能体在线状态、启用开关；悬停出「**执行**」按钮（智能体不可用 / 已禁用时置灰并给原因）。

卡片「更多」菜单：**复制**（生成「X 副本」）、**最近会话**（运行历史）、**导出 DSL**（YAML 配置导出交换）、删除。

库内支持：按名称 / 描述 / 智能体 / 提示词搜索；按状态筛选（全部 / 可执行 / 需处理 / 已禁用）；最近使用 / 按名称排序；「新建」下拉 = **自定义创建**（模板向导）或**导入 DSL**（粘贴 YAML）。

## 三、五段式配置

编辑器分五段导航：

| 段 | 内容 |
|---|---|
| **01 身份** | 头像（emoji / 图片）、名称、描述、**资源等级**、**数据目录**（三选：文件夹 / 知识库 / 代码库；代码库可多选，第一个为主工作目录） |
| **02 指令** | **系统提示词**（Markdown，运行时注入为系统提示词）+ **快捷操作**（编号列表：指令名 + 内容；运行时输入 `/` 选择后可编辑再发送） |
| **03 引擎** | **智能体引擎**（仅列已启用智能体）+ **默认模型**（可选 Auto）+ **权限模式**四档（自动 / 接受编辑 / 跳过权限 / 严格）+ 启用开关 |
| **04 能力** | **技能**与 **MCP 工具**多选（技能分技能库 / 项目 / 钉钉 dws 等分组；MCP 含已配置服务、内置原生工具、HTTP 接口、本机工具） |
| **05 规则** | Markdown 规则——运行时写入工作目录的智能体规则文件（AGENTS.md / CLAUDE.md / GEMINI.md 按引擎自动选择），由智能体原生加载 |

保存是**增量 diff 保存**，只提交变更字段。内置助手锁定：身份与系统提示词只读，快捷操作 / 引擎 / 能力 / 规则可调整；「恢复默认」一键清除自定义；内置不可删除。普通助手删除有守卫：**被计划任务或渠道绑定的助手不可删除**（先解除引用）。

## 四、运行：从执行到流式运行页

卡片「执行」→ 依赖检查 → **运行弹窗**：

- 输入框（`/` 唤出菜单：快捷操作 / 技能 / 工具，未安装的置灰标「未安装」）；
- 附件（多选文件）；模型下拉（默认 Auto）；**思考强度**五档（默认 / 低 / 中 / 高 / 最高，按智能体能力显示）；**权限模式**本次运行可临时覆盖；
- 数据目录为只读展示（回编辑器改）；知识库指向不可用或代码库未配置时会红字提示并暂禁发送。

点发送后进入**流式运行页**（全屏）：对话 / 轨迹两个视图（有记忆召回时还有「记忆」视图）；实时渲染消息、思考过程、计划、工具调用（输入输出可展开）、文件读写、问答卡（智能体中途提问直接作答）、权限确认卡、浏览器操作步骤、最终结果块（含 token 统计）。

- **权限审批**在运行页内完成：允许一次 / 始终允许 / 在此项目中始终允许 / 在此会话中允许 / 拒绝本次请求。
- **继续对话**：底部输入栏接着问（支持继续追加技能与工具，新资源以结构化方式挂载进当前会话）。
- **从此处分叉**：任意消息块上点「从此处分叉」——截断该点之后的对话，以该处上下文**开新会话**继续（会话页的「分叉」入口在这）。
- **停止**：确认后终止当前运行。

## 五、运行池与并发

- **前台 1 个 + 后台多个**：切到别的面板，运行页自动最小化到后台继续收流，任务中心同步可见；切回即恢复现场。
- **并发上限 3 个**（超出提示先完成或停止一个）；同一助手重跑会自动取消替换旧运行（旧输出转历史）。

## 六、历史与版本

- **最近会话**（卡片菜单）：搜索 / 分页 / 删除；打开为**历史模式**——静态回放整场对话与结果；「继续对话」会以历史上下文开一个新会话（旧运行实例随应用重启失效，属正常设计）。
- **版本历史**（编辑器右上角）：每次保存自动留版本（每助手保留 20 条），版本行显示变更字段徽章，可双栏对比 diff、**回退到此版本**、删除版本。

## 七、套餐（Recipe）

套餐是预组装的任务包（YAML：提示词 + 目标智能体 + 技能 + MCP + 上下文文件）。应用内置 8 个场景套餐，并已融入助手体系——**选中套餐的助手运行时自动按套餐编排执行**；计划任务的「从助手预填」也复用同一套运行管线（见[计划任务](./cron-tasks.md)）。

## 八、常见问题 FAQ

**执行按钮置灰？**
悬停看原因：智能体未安装 / 已禁用；到「智能体钩子」里装好钩子、在提供商配置好模型即可执行。

**运行卡在「启动进程…」很久？**
单次启动有 20 秒超时保护，超时会提示重试；持续失败检查该智能体 CLI 是否可用（终端里能跑通就行）。

**提示「当前已有 3 个助手任务在运行」？**
并发上限 3 个。先完成或停止一个，再发起新任务。

**重启应用后「继续对话」开的是新会话？**
运行实例随应用进程存活；重启后从「最近会话」打开历史并以历史上下文开新会话——这是刻意设计，避免续到已死的进程。

**权限确认卡显示「确认响应超时」？**
单次审批响应有 15 秒窗口，超时重试即可。

**导出 DSL 别人导入报版本不对？**
DSL 带版本号，高版本导出的配置低版本应用导入会拒收；升级应用后重试。

**规则的写入位置？**
运行时写入工作目录的智能体规则文件（受管块包裹，不覆盖你已有内容）；ZCode 引擎例外——不读工作区规则文件，规则会直接注入首条消息。
