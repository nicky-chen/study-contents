## 一、会话页是什么

入口：侧栏「核心」分组 → **「会话」**（第一项）。单页结构：页头（搜索 + 批量清理）→ 智能体状态条（运行会话数 / 待权限 / 权限决定）→ 历史会话浏览器 → 底部状态栏（含 Hosts 切换入口）。

它聚合的是**各家 CLI 智能体写在自己目录里的本地会话**——句芒智元直接扫描这些原始记录，不另存副本，所以在应用里看到的和你在终端里跑的完全同源：

| 智能体 | 会话位置 |
|---|---|
| Claude Code | `~/.claude/projects` |
| Codex | `~/.codex/sessions`（含归档） |
| OpenCode | 本地存储 / opencode.db |
| Gemini CLI | `~/.gemini/tmp/<项目>/chats` |
| Hermes | state.db + sessions |
| CodeBuddy / ZCode / Pi / DSH | 各自目录 |
| Cursor | 只读连接其数据库 |

每家智能体最多展示最近 500 条会话；句芒智元自己拉起的自动化会话（带 `[gromang-automation]` 标记的记忆提取等）不混进列表。

## 二、会话列表：来源与筛选

- **供应商筛选**：「全部 + 10 家智能体」下拉，默认跟随你当前使用的智能体——列表空了先看这里（空态会提示「N 个其他 Agent 的今日会话被当前筛选隐藏」并给「查看全部会话」按钮）。
- **视图模式**三选：列表（按活跃时间倒序，50 条一页加载更多）/ 分类（供应商 → 项目目录两级分组）/ 时间线（今天 / 昨天 / 近 7 天 / 更早）。
- **列表行**：智能体图标 + 标题（无标题时回退项目目录名）+ **实时状态点**（运行中呼吸绿 / 异常红，3 秒刷新）+ 相对时间。

## 三、搜索

页头搜索框，按 **会话 ID、标题、摘要、项目目录、原始文件路径** 匹配（第一次搜索时才建索引，不拖慢启动）。命中词在标题和消息里**高亮**；命中长消息会自动展开折叠段定位到关键词。

注意口径：这里搜的是摘要与元信息，**不是消息全文全文检索**——想搜某句话的原文，进会话详情后浏览消息（或用命令面板 ⌘K 直达会话搜索）。

## 四、会话详情：浏览与续聊

点开任意会话：

- **消息浏览**：虚拟列表滚动；超过 500 条只展示最近 500 条（开头有省略提示）；超长消息折叠为摘要，点「展开完整内容」看全文；角色标签区分 用户 / AI / 工具 / 系统。
- **元信息**：最近活跃时间、项目目录、原始文件路径——目录和路径**点击即复制**。
- **在终端继续**：一键在终端里恢复该会话（自动填好 resume 命令、定位项目目录；支持 macOS 主流终端，可在 设置 → 系统 → 窗口与终端 里选首选终端）。终端打不开时自动回退为「复制继续命令」。
- **复制继续命令**：详情头部常驻命令预览条（如 `claude --resume <id>`、`codex resume <id>`），复制后到任意终端手工恢复。
- **生成技能草稿**：把这次会话的执行轨迹蒸馏成候选技能，进[技能沉淀](./skills.md)草稿箱评审。
- **消息级操作**：复制单条消息；**加入记忆**——把某条对话直接写进该智能体的[记忆](./memory.md)（全局作用域）。
- **会话洞察条**：tokens（含缓存）/ 成本 / 请求数 / 安全预警 / 上下文压缩次数。

> 「分叉开新会话」在哪：会话详情页没有分叉；分叉在**助手运行对话**里——任意消息块上点「从此处分叉」，之后的对话以该处上下文开新会话（见[智能助手](./assistants.md)）。

## 五、今天的会话侧栏

主侧栏中部「今天」分组：全部智能体今天活跃的会话，最多 5 行（图标 + 标题 + 实时状态点）。点击直接跳到会话页并定位该会话（跨智能体会自动切好筛选、展开分组）。窗口聚焦或 30 秒自动刷新。

## 六、任务中心

入口：顶栏右上角**铃铛**（角标 = 运行中条数）。副标题一句话定位：「跨菜单保留正在执行的任务」——你切到任何页面，跑着的任务都在这里。

三个 tab：**运行中 / 已完成 / 已终止**（历史保留 7 天）。聚合三路数据：

| 来源 | 例子 |
|---|---|
| 助手运行 | 助手 / 套餐的执行（切页面不断线） |
| 跨域运行 | 智能化测试、知识库摄入、邮件任务 |
| 计划任务 | 最近执行记录（每任务最多 12 条） |

条目显示类型图标、标题、状态、失败原因首行、运行中实时耗时。能做的操作：

- **点击跳转**：直达对应面板（助手运行器 / 任务详情 / 测试页 / 知识库项目 / 邮箱）；
- **终止运行**（助手与跨域任务）：二次确认后终止，本次执行无法恢复；
- **暂停后续调度**（计划任务条目）：可逆操作不确认，已开始的这轮继续跑完；
- **清除记录**：清掉已完成 / 已终止条目；
- 失败自动 toast 提醒（主动终止的不打扰）。

## 七、批量清理

页头「批量清理」下拉，两种方式：

- **按选择清理**：进入勾选模式，选若干会话批量删；单条删除同样在详情菜单里。
- **按时间清理**：**必须先在筛选里选定某一家智能体**（防误清全量），然后选保留期（近 7 天 / 1 个月 / 3 个月），删掉保留期之外的历史。

两种清理都确认「此操作不可恢复」。**清理的对象是智能体的原始会话记录**（文件或其数据库条目）——删了之后在原 CLI 里也找不回来了，下手前想清楚。

## 八、常见问题 FAQ

**列表是空的，但状态条显示有会话在跑？**
供应商筛选默认跟随当前智能体，其他家的会话被隐藏了——看空态提示点「查看全部会话」。

**搜一句话的原文搜不到？**
搜索范围是 ID / 标题 / 摘要 / 目录，不含消息全文；进详情后浏览定位。

**历史只显示一部分？**
每家智能体最多加载最近 500 条会话；单会话详情只展示最近 500 条消息。

**「在终端继续」报错？**
终端未装或名字不匹配（去设置里选首选终端）；Linux 暂不支持终端恢复（自动回退为复制命令）；无恢复命令的会话（Cursor、CodeBuddy IDE 版）按钮置灰。

**CodeBuddy IDE 版会话没有正文？**
它的聊天正文只存云端，本地只有元数据。

**删了会话还能找回来吗？**
不能。清理删的是智能体的原始会话记录，非应用内副本，确认弹窗明示不可恢复。

**应用自己跑的任务为什么不出现在列表？**
句芒智元自动化产生的会话带内部标记，刻意不混入你的会话列表（它们在任务中心与对应面板可见）。
