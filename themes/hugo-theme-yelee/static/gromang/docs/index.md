# 句芒智元 · 使用者文档

> 所有文档围绕一句话展开：**让 AI Agent 不需要人值守**——权限秒批、定时巡检、手机远程审批，事实进记忆、套路进技能，网页上的活也接走。
> 第一次接触从《快速入门》进；想知道"全貌有什么"看《产品功能介绍》；要把某块能力用深用透，进下面的深度指南。

## 深度指南

与官网三大特色（**智能哨兵 / 经验沉淀 / 网页自动化**）对应，每篇都是"从零到跑通"的操作手册：写清每个入口、每个配置项、每一步会看到什么，以及容易踩的坑。

### 看护与值守

| 指南 | 一句话 | 你会用它解决什么 |
|---|---|---|
| [智能哨兵](./sentinel.md) | 把「需要人回来」的时刻接管掉 | 定时巡检服务状态与登录态、按规则盯钉钉群消息、值班 Agent 托管、告警一键带入终端处置 |
| [桌面伴侣](./pet.md) | 常驻桌角的看护形象 | 15 种状态实时演绎、权限气泡秒级审批、会话 HUD、托盘闪烁与全局快捷键 |
