## 一、记忆是什么

「记忆」视图由四个 tab 组成，各管一层：

| tab | 是什么 | 例子 |
|---|---|---|
| **记忆片段** | 长期记忆条目（会随使用进化的「事实」） | 「用户偏好报告用中文」「本项目用 pnpm 不用 npm」 |
| **记忆图谱** | 记忆片段及其关联的图视图 | 发现两条记忆其实说的是同一件事 |
| **情景语料** | 每次运行的对话原文（按轮成卡） | 排查「当时它到底说了什么」 |
| **记忆共享** | 把记忆池开放给其他 agent CLI 共用 | ZCode、Claude Code 注册后同池读写 |

一句话区分：**记忆片段是提炼后的事实，情景语料是原始对话**——前者会被注入进智能体的上下文，后者只是可检索的存档。

## 二、界面地图

- 主入口：侧栏「核心」分组 → **「记忆」**。页头右上「**记忆管理**」下拉：**记忆配置** / **记忆维护**两个弹窗。
- 托盘 / 桌宠菜单里有「记忆共享」直达项。
- 会话管理页：任意消息悬浮「**加入记忆**」——把这句对话直接写成一条记忆片段（全局作用域，可在记忆面板查看与编辑）。
- 助手运行页：召回胶囊显示「已召回 X 条相关记忆 · 常驻 Y 条」——每次运行实际用上了哪些记忆，点开即见。

## 三、记忆怎么来

三条来路，全自动的占两条：

1. **对话后自动提取（自动反思）**：客户端内每次运行收尾，提取模型自动反思对话、沉淀跨会话事实。有节流保护：每个助手每天最多 20 条、单轮最多 5 条——不会把记忆库灌成流水账。
2. **外部收割**：每 10 分钟扫描一轮已接入智能体（Claude Code、Codex 等 10 家）的本地会话日志，会话收尾（连续 10 分钟无更新）后走反思提取；带项目目录的落**项目记忆**，其余落**全局记忆**。
3. **手动录入**：记忆面板新建，或智能体在对话中调用记忆工具主动存。

**稳定度自进化**：每条记忆有稳定度分值，被召回命中即「续命」加分，长期无人问津则衰减；稳定度映射为三档生命周期——**活跃**（稳定）、**候选**（还行）、**观察**（快被淘汰，低于淘汰线自动出局）。列表排序：置顶优先，其后按最近强化时间降序。

## 四、记忆片段：查看与管理

统计条显示：记忆总数 / 活跃数 / 置顶数 / 情景轮次。列表行卡带：生命周期色条、稳定度药丸（悬停看口径）、证据数（被多少次对话支撑）、命名空间徽章、置顶 / 已忘记徽章、作用域徽章、命中次数与最近召回时间。

**搜索两种模式**：文本匹配（本地多字段子串，快）/ 相关性（语义评分排序，每条显示相关性分）。

**新建**（右下悬浮圆钮）字段：

| 字段 | 说明 |
|---|---|
| 归属智能体 | 这条记忆记在谁名下 |
| 作用域 | 全局 / 项目（填仓库绝对路径，可浏览选择）/ 会话（实际按**助手**隔离，下拉选助手）/ 渠道（按平台各自一套） |
| 命名空间 | 人工录入 / 用户偏好（长期习惯与要求）/ 基础（对话沉淀的事实）/ 高频（反复出现的行为规律） |
| 记忆内容 | 支持编辑与 Markdown 预览切换 |

单条操作：**编辑**（纯文本改内容）、**置顶 / 取消置顶**、**忘记 / 恢复**（软隐藏，不算删）、**删除**（确认弹窗明示「该操作不可恢复」）。

同内容重复存入不会重复建档——自动去重并给原条目加一次证据（幂等强化）。

## 五、记忆配置

「记忆管理 → **记忆配置**」弹窗，核心字段：

| 配置 | 说明 | 默认 |
|---|---|---|
| 启用记忆系统 | 总开关；关闭后不再采集、不再注入，已有记忆保留不动 | 开 |
| 对话后自动提取 | 自动反思的开关 | 开 |
| 收割外部智能体会话 | 外部收割的开关 | 开 |
| 提取智能体 / 提取模型 | 谁来干提取的活；Claude / Codex / Gemini / Hermes / opencode / ZCode 走 API 卡直连，其余已装引擎走「运行时」单次调用（更慢更贵，会有提示） | — |
| 召回数量 | 每次注入最多带几条 | 3（可调 1–20） |
| 召回最大字符数 | 注入记忆的总字数上限 | 1000（可调 100–10000） |
| 整固阈值 | 相似记忆攒到多少条触发合并 | 20（可调 8–1000） |
| 自动整固 / 允许智能体回退 | 合并去重与降级策略 | — |

## 六、记忆图谱与「问记忆库」

记忆图谱 tab：全部记忆片段的关联图（按命名空间着色，带图例）。节点可点开详情、行内编辑 / 删除；页头「跳转到记忆节点」可按名检索直达。画布角落有**「问记忆库」**聊天圆钮——直接和你的记忆池对话（「我上次为什么否了那个方案？」）。

## 七、情景语料

每次运行的对话原文，每轮一行、按轮成卡。三种操作：

- **搜索**：服务端分页全文检索；
- **导出**：可选时间范围（全部 / 近 N 天 / N 天前），导出的是纯文本对话存档；
- **清理**：同样带时间范围 + 二次确认，确认文案会说明**「长期记忆保留」**——清情景语料不会动你的记忆片段。

## 八、记忆共享：外挂给任意 CLI

官网说的「记忆外挂 / MCP 同池」就是这里。顶部是常驻注册区：**10 家 CLI 各一个开关**（Claude Code、Codex、Gemini CLI、opencode、Hermes、Cursor、DSH、CodeBuddy、Pi、ZCode）+「**一键全部注册**」。

**注册一次做了四件事**：写入该智能体的 MCP 配置（接上 gromang-memory）→ 部署内置记忆技能 → 在它的全局规则文件里写入「先查再存」的记忆纪律受管块 → 把高价值记忆投影进规则文件。注销时对称移除，不留残余。

> 没开启「对话后自动提取」时，注册区会显示黄底警示——先去记忆配置里打开，否则外挂的智能体只能查到空池子。Codex 注册后需在 Codex 侧手动信任钩子。

三个子层：

- **全局记忆**：按智能体分池聚合（总数 / 收割数 / 桥接写入数 / 最近写入）。点开池明细可按命中情况筛选（近 7 天 / 30 天命中、零命中超 14 天……）、删除单条、**投影到规则文件**（预览 diff → 编辑内容 → 写入，把选中的记忆放进该智能体的规则文件随每次系统提示生效）、查看冲突检测。
- **项目记忆**：按仓库展示已建代码知识索引的记忆条数、四实现徽标（GitNexus / graphify / codegraph / Understand）、图谱新鲜度、「项目记忆纪律块」开关。空态会指路：知识库 → 代码图谱去初始化。
- **会话记忆**：context-mode 状态卡——实时上下文节省统计（拦截次数 / 已省 token）、每家智能体的同步状态。需要 Node ≥ 24.15。**「记忆互通」**开关（默认开）：句芒的全局记忆按项目写入 context-mode 数据根，让会话层检索也吃上同一池记忆。

右下角「**手动接入其他工具**」：给不在 10 家清单里的工具生成接入配置——填一个自定义池名，得到桥接 URL 与 `mcpServers` 配置片段，贴过去即可。

## 九、记忆怎么被智能体用

客户端内每次运行组装上下文时，自动注入记忆块，分三区：

1. **学到的上下文**（对话沉淀的事实，活跃条目）；
2. **固定偏好**（用户偏好命名空间的活跃条目）；
3. **与本次消息相关的记忆**（过检索门的逐条召回，按召回数量 / 字符配额截断）。

注意门槛：智能体的**资源等级达到 L3 及以上**才会注入记忆（低等级精简上下文省 token）——配置了记忆却没生效，先查这一条。注入命中的记忆会自动「续命」加分。

外部智能体则通过 **gromang-memory** MCP 主动用两个工具：`memory_recall`（查记忆）与 `memory_store`（存记忆），全局与项目作用域可见；总开关关闭时桥上直接拒绝。

## 十、记忆维护

「记忆管理 → **记忆维护**」弹窗：

- **AI 整固记忆**：相似记忆自动合并去重（阈值见记忆配置）。整固前自动做归档快照，可回滚——回滚确认会说明「归档将完整替换当前智能体的记忆」；
- **从 markdown 重建**：用导出的 markdown 完整回灌（同样明示「完整替换」）；
- **立即重算**：手动触发一次全量稳定度重算（平时每 30 分钟自动跑）。

## 十一、安全与隐私

- **密钥拒绝入库**：内容疑似密钥 / 令牌（`sk-`、api-key、bearer、GitHub token 等）直接拒写，弹「内容疑似包含密钥/令牌，拒绝写入记忆」；
- **提示注入防护**：含「忽略之前指令」类话术的条目**注入时自动跳过**（原文保留，可人工清理）——网页上捡来的「记忆」不会被当作指令执行；
- **全本机**：记忆存 `~/.gromang`，不上云；外部可见面只开放全局与项目作用域（会话 / 渠道作用域是客户端内部身份，桥上不可见）。

## 十二、常见问题 FAQ

**手动存记忆被拒？**
两种原因：内容为空，或被密钥检测拦下（内容里别带 token / API Key）。

**配置了记忆，运行时却没注入？**
按序排查：总开关是否开着 → 智能体资源等级是否 L3 及以上 → 召回配额是否过小 → 该智能体作用域下确实有活跃记忆吗。

**注册智能体时提示「未检测到安装目录」？**
先安装 / 初始化对应 CLI 再注册（注册会中止，不会写入任何配置）。一键注册的汇总会显示「已注册 N 家（跳过未安装 M 家，失败 K 家）」。

**外挂的智能体不主动查记忆？**
注册写入的规则块要求「先 recall 再回答」的纪律；若智能体不听话，检查规则文件里受管块是否被手动删过，重新注册一次即可写回。

**会话记忆（context-mode）显示 Node 缺失？**
context-mode 需要 Node ≥ 24.15，升级 Node 后回来看看。部分智能体暂无接入，属正常。

**删除记忆片段能找回吗？**
不能——确认弹窗已明示不可恢复。不确定就先「忘记」（软隐藏，可恢复）。

**清了情景语料，记忆片段会少吗？**
不会，两者独立存储；清理确认框里写明了「长期记忆保留」。

**Hermes 自己也有个「记忆」工具，是一回事吗？**
不是。那是 Hermes 专属的内置工具集，与记忆面板是两套体系；想统一管理就走记忆共享注册。
