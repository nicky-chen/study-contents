## 一、渠道地图：两个面板

入口：**设置 → 网关互联**（页头副标题就是「远程访问、通信渠道与消息推送的接入配置」），侧栏底部「移动端远程控制」图标可直达。渠道分两个手风琴面板：

| 面板 | 渠道 | 方向 |
|---|---|---|
| **通信渠道** | 钉钉（dws 个人号）、微信、Discord | **双向**：IM 里收消息、指挥助手、收回复 |
| **消息推送** | 钉钉 Token（群机器人）、钉钉 CLI、企微群机器人、邮件通知、Webhooks | **仅出站**：向外部发通知（计划任务投递等） |

通用接入流程（凭据型渠道）：填表单 → 点「**测试并连接**」→ 校验通过自动启用并启动后台任务。没填凭据直接开开关会被拦：「请先填入凭据并点击测试连接」。

> 已保存凭据的渠道，开关只能在桌面客户端操作（网页端不回传凭据，防止密钥外泄）。应用重启会自动恢复已启用的渠道。

## 二、双向 IM 接入

### 钉钉（dws 个人号）

以你当前登录的钉钉账号身份收发群消息，**不需要群机器人**：

1. 前置：设置 → 授权 → **钉钉（DWS CLI）**登录；
2. 通信渠道 → 钉钉卡：
   - **接入群**：下拉拉取你的群列表（可搜索）；
   - **回复身份**：默认「以我的身份回复」，可选群内机器人（选中后以机器人身份回话，且 @机器人 即触发）；
   - **触发关键词**（必填）：空格 / 逗号分隔，消息**命中任一**才派发助手——没命中只是普通群聊，句芒智元不介入；
3. 点「**测试并启用**」。

收发节奏：每 10 秒拉一轮群消息；同一群每分钟最多派发 3 条（防刷屏）；自己的回复有回环防线不会自问自答。

### 微信（扫码）

1. 通信渠道 → 微信卡 →「**开始扫码登录**」，出二维码；
2. 微信扫码并确认后**自动启用**，无需填任何凭据；
3. 二维码 5 分钟有效，过期点重试；会话过期（长时间后掉线）时重新扫码即可。

微信渠道只处理**文本与语音**消息（图片、文件跳过）。

### Discord（Bot Token）

1. 去 [Discord Developer Portal](https://discord.com/developers/applications) 创建应用拿 **Bot Token**；
2. 通信渠道 → Discord 卡粘贴 Token →「测试并连接」（校验通过自动启用）；
3. 后台长连接收发频道与私信消息，断线自动重连。

## 三、消息推送（仅出站）

| 渠道 | 关键配置 | 说明 |
|---|---|---|
| **钉钉 Token**（群机器人） | Webhook 的 access_token；可 @ 手机号 | 群设置 → 机器人里拿 token；markdown 消息 |
| **钉钉 CLI** | 群 ID（openConversationId） | 以你的 dws 登录身份直发，无需群机器人；群 ID 可在终端 `dws chat group list-my-groups` 查 |
| **企微群机器人** | Bot ID（webhook key）；机器人开了签名校验则 secret 必填 | 从企微群机器人页面获取；应用模式下另需企业 ID / 应用 ID |
| **邮件通知** | 邮箱地址、密码（授权码）、SMTP 服务器 | 发件账号可与主面板邮箱共用 |
| **Webhooks** | 推送 URL（POST JSON）；密钥（可选） | 配密钥后出站带 `X-Signature` 签名、入站可校验外部回调；也可配置端口接收外部系统的 HMAC 签名回调 |

这些出站渠道是[计划任务](./cron-tasks.md)结果投递的去处：任务里选了哪个渠道，跑完就投到哪。

## 四、在 IM 里指挥助手

双向渠道里的消息命中触发条件后，会派发给助手执行并把回复送回 IM。派发给谁、带什么能力，在渠道展开的「**Agent 运行时绑定**」里配：

- **绑定助手**：整份复用该助手的智能体、权限模式、技能、MCP、提示词、工作目录——渠道变成这个助手的远程入口；
- **不绑定（自定义）**：渠道独立选智能体与模型，并勾选**数据感知能力**（受限只读工具）：趋势资讯 / 邮箱 / 桌面控制 / **用量统计 / 会话历史 / 定时任务**——让 IM 里的助手能查这三类本机数据（只读精选工具，不提供 SQL，密钥表物理不可达）。

**在 IM 里审批权限**：助手要执行命令 / 改文件时，审批请求会推到 IM。直接回消息：

| 回复 | 效果 |
|---|---|
| `审批 y` | 本次放行 |
| `审批 yy` | 本会话内放行 |
| `审批 w` | 始终允许此类操作 |
| `审批 n` | 拒绝，助手继续 |
| `审批 stop` | 拒绝并中断本次执行 |

（英文 `approval y` 同样有效；裸 `y` / `n` 不触发，防误触。）

## 五、配对码安全模型

陌生人的消息不会直接到助手手里：

1. 首次收到陌生用户消息 → 句芒智元生成 **6 位配对码**（5 分钟有效），直接回复给对方；
2. 客户端渠道面板出现「**待审配对**」条目（显示名 + 配对码 + 倒计时），你点「**通过**」或「**拒绝**」；
3. 通过后对方进「已授权用户」列表，此后消息直接派发助手；可随时「撤销授权」；
4. 改渠道凭据前需要先清空授权用户（面板会锁定提示）。

例外：钉钉 dws 形态**没有配对码**——群聊里回配对码是噪音，触发关键词本身就是门槛（命中关键词即视为授权）。

## 六、消息去哪了：排查「没回复」

每封入站消息都有归档记录（渠道收件箱），状态机：**待处理 → 已回复 / 失败 / 超时**。回复超时上限 10 分钟；助手执行失败会把**真实失败原因**回给你（不粉饰）。

「消息发了没回复」排查顺序：

1. 有没有命中**触发关键词**（钉钉）；
2. 对方是不是**还没通过配对审批**（微信 / Discord）；
3. 渠道卡片状态是否「已连接」（微信会话过期 / Discord 掉线都会显示）；
4. 收件箱归档当前为 API 级能力（暂无专门界面），失败与超时会在渠道侧留痕，配 `run_id` 可到会话面板对应运行里看执行详情。

## 七、常见问题 FAQ

**微信提示连接失败 / 二维码总过期？**
二维码 5 分钟一次性；「连接登录服务失败」是网络问题，重试即可。掉线后渠道状态会标降级，重新扫码恢复。

**钉钉消息不触发？**
三个可能：没命中触发关键词（关键词大小写不敏感、命中任一即可）；触发频率超每分钟 3 条上限；或 dws 登录态过期（设置 → 授权里看）。

**企微机器人测试连接失败？**
测试要求 Bot ID 和 secret 都非空——即使机器人没开签名校验，测试时也先填上 secret。

**助手回复「回复超时未能完成」？**
单次执行 10 分钟未见终态按超时处理；任务本身可能还在跑，去任务中心 / 会话面板看运行状态。

**Webhook 入站回调收不到？**
入站地址必须带 token 路径段（以渠道详情为准），且请求需按约定做 HMAC-SHA256 签名（`X-Signature` 头）。未配密钥的入站回调会被拒。

**在网页端（webui）能改渠道配置吗？**
能看能配新凭据，但已保存凭据的渠道开关必须在桌面客户端操作（安全设计）。
