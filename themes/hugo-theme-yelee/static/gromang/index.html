安装

  1. 下载上面与你系统对应的安装包（macOS 选 Apple 芯片或 Intel 版）。
  2. macOS 打开 .dmg 拖入「应用程序」；Windows 双击 .exe 按向导安装。
  3. 启动后桌宠出现在屏幕角落，进入 设置 → 提供商 填入 API Key 或 OAuth 登录即可。
macOS 提示：提示「无法验证开发者 / 已损坏」怎么办

前往 系统设置 → 隐私与安全性 点击「仍要打开」；或在终端执行 xattr -cr /Applications/句芒智元.app 后重新打开。
